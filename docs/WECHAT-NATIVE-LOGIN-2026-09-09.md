# 微信原生手机号与头像登录实现

2026-09-09，开发版本 0.1.5-dev.20260909。

## 研究结论与本次实现

用户描述的手机号确认是微信原生手机号授权组件，可以放在登录按钮上。小程序得到的是本次选择的手机号授权凭证，服务端兑换被选中的号码；不会收到用户全部电话号码列表，也不自行制作号码选择器。原生界面是否展示其他可选号码，以微信客户端实际界面为准。

头像采用 chooseAvatar。首次没有已保存头像时，在原有会员账号页面呈现“使用微信头像并继续”和“稍后设置，继续使用”；选择后立即处理、保存并进入原目标页面，不必去设置页或再点一次保存。已有头像的会员登录直接加载，不重复要求选择。后续修改仍在设置页。

底部登录按钮在手机号能力可用时绑定 getPhoneNumber，由原生回调驱动 wx.login，避免按钮点击与授权回调并发创建身份。身份 code 与手机号 code 分开使用；先恢复会员身份，再将本次手机号绑定给当前账号。手机号拒绝或绑定失败不会把已成功登录误报为失败。原账号资料不被登录默认名称覆盖。

首次头像自动保存前读取当前资料版本，提交头像时保留原昵称、微信号与社区展示选择。保存冲突时提示重试，不冒充保存成功。退出或切换账号的迟到图片处理不再写入当前账号。

## 依据

- [腾讯云 CloudBase 获取用户手机号组件](https://docs.cloudbase.net/lowcode/components/wedaUI/src/docs/compsdocs/wxOpen/Phone)：微信小程序真实运行环境、原生确认及拒绝事件、认证及主体限制。用于核对用户所说的授权流程，不把其低代码事件名直接当原生 API。
- [微信团队头像昵称组件示例](https://github.com/wechat-miniprogram/mp-user-avatar/blob/master/README.md)：chooseAvatar 与昵称填写能力。该仓库已归档，未安装归档组件。
- [腾讯云小程序隐私保护适配说明](https://cloud.tencent.cn/document/product/1301/97930)：测试前在微信公众平台设置中完善用户隐私保护指引信息类型。
- 本项目安装的 miniprogram-api-typings 5.2.3：getUserProfile 标有官方规则调整警告；原生 getPhoneNumber 事件、Canvas 与头像输入按 SDK 核对。未采用旧接口默认头像冒充真实微信头像。

微信开发文档部分页面本次无法直接读取；未把第三方 SuperApp 的相似 API 作为微信小程序证据。

## 尚需完成

手机号服务的生产开关当前仍为 false。先由管理员在微信后台补充隐私指引中的手机号用途，确认手机号快速验证能力及可用额度；再启用服务开关，并由本人在真机确认号码。此前真实平台报错 112（隐私声明配置）。当前不能宣称号码选择已在真机成功。

浏览器安全策略明确禁止代理操作微信公众平台，不能通过其他浏览器或接口规避。已向用户提供手动配置步骤，并按截图指路。管理员未完成前不提前启用不可用入口。

完整 16 路由 / 160 状态验收仍未完成；本报告仅说明当前登录改动的测试与实际观察范围。
