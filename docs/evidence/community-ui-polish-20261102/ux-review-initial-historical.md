## 流程与主次关系

- 社区 `+` → 相册／相机／写文字三入口。前两项才请求媒体相关授权；仅展开菜单、或在系统相册／相机选择器取消，不创建草稿。进入编辑后取消仍走既有精确清理与脏稿守卫。我的投稿是独立次入口。
- 选图 → 本地图片编辑 → 下一步 → 内容编辑；文字 → 真实 PNG 卡片预览 → 下一步 → 内容编辑。“直接写正文”保留次入口。
- 图片效果有未应用修改时，应用是可执行动作，下一步禁用；应用成功才换成本机新文件。固定动作区使这一步不再需要先找到滚动位置。
- 内容编辑中，公开能力关闭或未确认时仅展示存草稿；开放时存草稿次于发布。发布仍走真实审核与复核状态，结果页没有宣称立即公开。
- 本轮只调整既有展示、文案与上述固定动作布局；没有改公开 UGC 配置、服务契约或数据归属规则。
