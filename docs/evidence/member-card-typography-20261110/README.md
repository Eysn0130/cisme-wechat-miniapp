# 会员卡积分数字精修

用户最终明确要求用Impeccable修正卡面“850”显乱的问题。沿用已经选定的185px会员卡、分隔线、会员编号底栏、品牌梅紫及长按柔光。对应PRD `PROFILE-CARD-TYPE-01`，此前上传0.1.35的明确授权继续有效。

按Impeccable 4.8.2的typeset与polish流程分别进行独立排版评估和机械扫描。视觉问题是Georgia旧式数字的字高／基线形态，原tabular-nums只处理宽度；机械扫描两次均为空，未识别该字形问题，也没有WXSS覆盖证明，不能将其当作原生验收。字体复用全局系统无衬线、400字重、lining-nums与tabular-nums。品牌CISME保留衬线，避免把品牌展示和操作数据混作同一角色；不增加字体资源或依赖，不改数据及编号。

常规数字字号与行高保持2.375rem/1.1，390px官方模拟器实测38px／41.8px、卡高185px。8位及以上改为1.75rem：初始32px系统字体导致375px屏上的十位整数换行，已在独立attempt目录保留原哈希与未通过范围；最终28px紧凑态使2147483647完整单行呈现。仍允许极端系统字号下自然增长，不使用nowrap裁切，不逐字偏移，也不引入滚动数字或虚构积分。
