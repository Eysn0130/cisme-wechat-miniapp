## 最终行为

- 社区复用现有双列、作者行、文字页签、共享 feed 和错误提示。能力接口失败保留“未知”并可重试；正式与 legacy 来源分别按真实 `publicEnabled`／`ugcGoLiveGate` 处理。权限拒绝立即清缓存和游标，迟到成功不能回填；同身份暂时失败保留分页位置；精选先呈现后的新分页不被首屏迟到聚合覆盖。分享等请求撤销会话也会清除私人投影，并保护新身份、环境及 attempt。
- 图片 load 保存本资源比例，重试保留画布和作者行，旧资源回调无效。保留产品已有的 200ms 原生淡入；没有实现或宣称视频的 14px／700ms blur。首次从未测量的资源仍用原 widthFix。
- 上传沿用现有适配器，只接受真实合法、非倒序的字节目标；未知 PUT、整理、素材确认不造百分比。普通素材确认 POST 前持久化原 ID 与 pending，备份失败先停止写入；先只读核对，显式继续才做原 ID 幂等确认。本地预览过期仍可核对。分块读文件期间取消后不再多发下一块，多图中断保序。编辑替换候选仍限页面内存，不宣称跨重启恢复。对应 `NATIVE-LOAD-02/04/05`、`COMPOSE-IMAGE-01`、`COMPOSE-ACTIONS-01`、`COMPOSE-PUBLISH-INTENT-01`。
- 底栏按最后追加要求成为“未选中线框，选中白色实心 SVG＋白字＋紫色填充胶囊”。四个图标复用已安装 Phosphor 的 fill 权重；细紫轮廓、70px 底板／60px 按钮、原生路由与 280ms 方向拉伸回弹保持。旧线框在实心层淡入时退场，避免透出；白色仅在胶囊到达后出现。静态／低动效默认就是完整末态，禁用中的当前项也保持白字对比。

共享底板使用单层 20px blur／135% saturation 和中性白半透明材质，选中层使用葡萄紫填充与边缘高光。参考 Apple 官方 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)／[Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)，这是微信原生中的视觉近似，不是系统 Liquid Glass 或真实折射。护理、首登、积分反馈和轮播结构没有改版；原线程后续访客商城／护理恢复差异另列待协调。

## 复现

官方 Skill 打开当前工作树项目后，用 `qa-source/session-baseline.mjs` 仅在内存隔离原会话。`filled-selection/replay.mjs compile <前缀>` 编译；`filled-selection/run-navigation.mjs <375或412> --hold` 运行受控导航，`record-tap.mjs <宽度> <目标>` 只记录已由 CUA 实际点击的目标，最后 `run-navigation.mjs finish <宽度>` 清理并恢复。所有 CLI 调用串行限速。社区受控场景使用 `selected-final/replay.mjs community <宽度>` 与 `run-extra.mjs <宽度>`；先只读确认基线，不在结果未知时重复业务操作。真实私有上传不是可无条件重跑的受控 fixture，不用脚本重复新增会员数据。
