## 改动及契约

- 精选先呈现时，推荐的读取仍有独立的在途状态；切频道不会将未完成或曾失败的读取显示成空结果。推荐两来源都成功才确认就绪；部分失败给恢复提示，双源失败保留同身份快照，401／403 抵达立即清除推荐投影且阻止迟到回填。独立成功的精选快照不随推荐失败清除。对应 `NATIVE-LOAD-02/05`。
- 复用共享 feed 模板、双列和作者行。真实图片 load 回调记录本资源比例，错误提示不占正常文流；重试保留原画布，不重挂标题或作者。图片仍用原生产品已选的 200ms 淡入，不宣称还原视频 14px／700ms blur。首次完全未知资源没有服务端比例提示时，仍使用原来的 widthFix 行为；本轮的几何保证针对已测资源重试与已有内容刷新。
- 上传只接受同一次传输的合法、非倒序目标；字节分母冲突后回到未知状态。无可测事件的 PUT、分块整理、素材确认分别呈现，不用计时器编百分比，不将传输完成当作发布成功。
- 确认超时保留原素材 ID；「重新核对」只读查原 ID。若仍不可确认，另由本人明确点击「继续确认」才重试原幂等确认。确认过程中离页后重新核对，不能自动再写。普通图片沿用现有同会员、稿件和版本的七日本机备份；编辑替换的候选仍只在当前页面内存，原图到确认前不替换。对应 `COMPOSE-IMAGE-01`，不新增公开意愿。
- 全部本地选择先入队，再串行上传；中断后尚未开始的图片可见且保持次序，不自动重传。失效本地路径不显示无效的上传重试。原有去发布、存草稿、键盘与权限互斥保持原逻辑。

## 底栏追加范围

按用户点名的底栏原线程继续精修；保留四项导航、原图标、70px 底板／60px 按钮、原生切页、业务互斥及 280ms 方向拉伸回弹。仅调整现有 WXSS：中性白磨砂底板、较轻阴影、细轮廓和较浅的紫白选中层；当前标签 13px、选中字重 500。共享底板使用 20px blur／135% saturation，白色填充从 .84 到 .82；移动胶囊继续只用填充与高光，不叠加滤镜。低性能分支实底，减少动效类显式禁止胶囊动画，高对比媒体分支保留清晰轮廓。

依据 Apple 官方 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars) 和 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)，将玻璃限制在导航层、保留短标签，优先保证复杂背景上的可读性。这里是适用于微信原生渲染的材质近似，不是 Apple 系统 Liquid Glass，不具备其自动明暗反转或真实光学折射。

物理 iOS／Android、读屏和帧率；微信对系统减少动态／透明度及高对比偏好的实际传播；真正不支持 backdrop 的渲染器；当前包真实会员上传、编辑替换和公开发布；首次未知图片比例；14px／700ms blur；全部 48 路由、字号与状态矩阵仍未通过本轮验收。作者主页旧封面分支的局部失败恢复没有随社区页自动升级。全局视觉清单继续标为 blocked。

本次 PR 修复社区状态恢复，并按追加请求精修共享底栏材质。护理页、首登、积分反馈与轮播结构未改。代码合并判断与正式发布验收分别记录；不以模拟器和受控上传代替真实会员端到端或完整设备验收。原工程未提交工作保留，本轮不合并 main、不部署或上传体验版。远端 CI 以 PR 当前 head 的回执为准，不引用已取消的旧候选运行。
