# 记录页历史版式与滑动修正

本轮依据用户对0.1.13的反馈：记录页版式尚未被接受；左滑应稳定露出删除胶囊，不能闪退、打开详情或直接删除。沿用PRD附录M与现有日常记录权限、版本、确认及撤销规则。

## 历史版式

已回溯五类实物：早期日历与最近记录、线形周期账本、环形数字与周期卡、近期较高数字封面、0.1.13紧凑页头。早期Web原型仅用于视觉比较；其中连续天数、趋势百分比和演示记录不能恢复为真实事实。系统功能字体、胶囊避让、安全区和一天一份真实记录继续保留。无真实周期不展示周期进度或管理动作。

原图仍保留各自来源与历史范围，不以旧图宣称本轮原生通过。用户的版式选择与本轮手势修复分开处理。

## 手势契约

| 场景 | 预期行为 |
|---|---|
| 快速左滑、缺少中间move | 使用松开事件的最终触点完成方向及位移判定；只展开操作区，不触发详情。 |
| 最后一次move较短、松开位置更远 | 最终位置参与吸附，不能按过时位移收回已经完成的左滑。 |
| 横向与纵向 | 维持方向阈值和纵向优先；锁定的横滑不被相同滚动位置或轻微尾部滚动打断。新的明确竖滚正常收起操作区。 |
| 重复读取 | 同一ID和版本的读取成功不重置已展开或正在拖动的行。记录被更新、移除或身份变化时取消旧手势。 |
| cancel、多指、中断 | 取消是终态；随后迟到的move/end不能重新展开。离页或换人后也不能复活。 |
| 滑动后的tap | 同一手势带来的点击不打开详情、不收起删除区；下一次明确点击按现有语义处理。 |
| 删除 | 滑动本身无写入；点击胶囊后才显示原生确认，取消保留记录。确认删除和撤销仍由服务端所有权、版本和稳定操作编号约束。 |

## 依据与验证

旧源实际原生事件记录已捕获end-only左滑后误开详情，以及展开后真实接口重读使同一行收起。滚动仲裁与取消后迟到事件另用离线页面反例核对，不把未复现的手机行为标为实测。

平台依据为现有官方小程序事件类型、开发工具注册接口和本轮原生事件；官方网页此次未能读取，不以其他小程序平台文档代替微信依据。不引入Web手势库，不用全面拦截touchmove破坏页面竖滚。

当前源码验收需重新计算包哈希，核对快速与分段滑动、右滑、轻微斜滑、普通点击、同版本回读、取消确认以及小屏大字号。原始页面／接口证据仅存本地私有临时目录；公共记录只保留聚合结果。全40页状态、物理真机和真实周期正向路径不由本轮局部检查推定通过。
