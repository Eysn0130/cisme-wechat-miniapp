# 活动旅行套装、统一页签与卡券精修

本次代码位于 `codex/activity-travel-rewards-20261113`，PR #101。产品边界见 `docs/product/CISME-活动奖励与体验券-20261113.md`，卡券动效契约见 `docs/product/CISME-卡券材质与动效-20261113.md`。这是原生微信小程序实现。

## 范围

- 仅获奖会员各一张兑换券；净润/净屑二选一；三个旅行装组件独立记账，共用护发乳库存。原子扣券、预占、取消释放、到期和售后均由服务端核对。
- 真实领取订单确认收货后发满198减20正装券，30天有效；商品范围快照、下单锁券、签名支付回调核销、取消/退款恢复均接入既有交易流程。积分按券后商品金额计算并可选择不用。
- 后台沿用现有权限：活动配置、真实库存登记、获奖名单发券、领取履约与有界导出。无真实库存及名单时不生成实物资产或奖券。
- 10个页面的11组同类顶部Tab统一复用社区样式组件；表单选项、SKU和底部导航保留各自业务语义。
- `copy-refinement.json` 逐项记录68处精简决定。必要的费用、资格、期限、操作结果及异常恢复仍可访问。AGENTS.md已加入用户指定的中英文原则。
- 会员卡、旅行兑换券和正装券使用共用原生材质层。首次出现/到账/长按仅播放单次扫光，触摸只移动反光；卡体和文字固定。纵向滚动、隐藏、中断和低性能/减少动态效果有退让路径。
