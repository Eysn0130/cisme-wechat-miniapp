# 会员卡精修与长按柔光

本轮用户基于上传图像明确要求收紧会员卡上下留白，并参考 Impeccable 做精致设计与轻量惊喜。此前“上传0.1.35体验版”的明确授权继续覆盖本轮修订，未另行重复询问；本轮开始时该版本尚未发起upload。

PRD附录M：`PROFILE-CARD-02`、`PROFILE-CARD-MOTION-01`。保持已确认的会员身份、同一账本积分、护理页“详情”入口、头像昵称与服务列表。只精修原生会员卡，没有改后台、数据库、价格、资格或积分规则。

## 精修结果

相同390×844官方模拟器和相同合成数据下，卡片宽362px保持，默认高度237→160px，减少32.5%。通过上下padding、品牌字号、内容组间距和底部留白压实比例；16px圆角、浅色细边、淡化弧线与梅紫层次保持既有视觉。移除卡片外层宽阴影，信息优先于装饰。根据用户最新截图反馈，卡面删除重复“会员卡”标签、冻结／预占、到期和欠分提示，只呈现品牌、会员身份、真实可用积分与积分入口。详情中的完整账本和使用限制保留；长内容自然撑高，不以固定height裁切。

长按的惊喜是卡面材质的一次回应：640ms珠光扫过，支持设备尝试轻触感。普通点击仍立即进入原积分页，不等待动画；没有数值跳涨、额外积分或交易。默认状态不自动播放，700ms收尾清理，重复触发不叠加，离页／卸载／重新读取同步清理。低性能降级与减少动态效果路径保留原点击任务。
