# 隐私范围与主体联结

`docs/privacy/subject-data-map.json` 由本轮一次性合成库迁移后的 schema 元数据生成；没有读取旧数据库或个人行。125 张表、102 张有候选 member 外键路径，每列明确列入现有导出白名单或排除集合。测试将实际迁移 schema 与该清单逐列比较，新表/字段不能无声继承授权。

候选 FK 路径不等于主体所有权。作者、举报人、审批人、推荐人、买家等分别处理；polymorphic audit/outbox/idempotency/hold/bill 关系附专门说明，禁止通用 UUID 联结或直接导出 JSON 快照。当前导出仍只实现 test-only member_profile_only；全账号字段投影、对象副本、搜索/缓存和备份后的权利处理执行器尚未实现，属于技术工作，不是负责人补截图事项。

现有合成 privacy-rights 测试覆盖请求身份、双人审批、过期/撤回下载、重复执行、部分失败恢复、hold/保留例外及审计。生产自动删除保持关闭；财务/渠道/交易审计不得随账户级联硬删。留存期限、合法依据、人工受理责任与时限须责任人批准；本轮没有编造具体期限。恢复生产备份前需在隔离位置重放经审查的权利处理清单和有效 hold，不能把已删除内容恢复为公开可用；该生产恢复联动尚未实现和实测。
