## 当前界面与接口

删除“公开投稿暂未开放…”等常驻提示、教学说明、发布说明大块、照片/标题/正文重复标签和常显计数。标题正文直接输入，图片与添加按钮横排；必要确认集中到一行发布设置入口，点击从底部展开。接近字数上限及真实上传、审核、失败、结果未知等状态仍按需显示。

AI选项、事件、页面数据、新备份字段、保存/提交参数和后台强制校验均已移除。新请求不传AI字段，更不伪造“用户已选择”。旧数据库修订和审计未重写，兼容旧客户端元数据；省略字段时新稿保持unknown，旧稿沿用已有值。未将字段缺省认证为纯人工内容。

内容权利与审核后公开展示仍由本人分别确认；缺确认时发布打开面板，齐备后清除对应错误。面板打开收起键盘，离页和提交成功关闭。私稿保存无需打开面板或同意公开。此前所有精确归属、版本、未知结果、中断、下架/删除保留与诚实退出保护继续存在。

## 范围与复现

小程序页面TS/WXML/WXSS/JSON与中央加号组件逐文件相同，见 `source-proof.json`。模拟器仅将接口、认证、备份存储及公开详情往返刺激页替换为内存夹具。截图中发布能力开启、审核结果、公开版本与删除均为明确的隔离场景刺激，不能当作正式账号已通过审批或真实公开上线。图片为已有品牌包内样本，不是真实UGC。接口正向闭环由另外的隔离接口测试核对。

执行 `../community-compose-followup-20261101/prepare-native-followup.py` 复制当前真实源码并准备离线夹具；本目录的 `capture-native-flow.py` 和 `capture-responsive-followup.py` 记录原生采集步骤。切换设备会重启模拟器；本轮所有截图完成后，恢复390px设备的首次运行时查询曾超时，失败回执留在 `responsive-restored-runtime.json`，恢复结果另存，不把失败改标为成功。

本轮未部署服务器或上传体验版，未开启正式公开UGC、未新增真实账号验收数据。真实手机键盘、系统字体缩放、手势、屏幕阅读器和加号手感仍未实测；静态截图不代替触达实测。全局40路由与真机矩阵继续保持blocked。此前e8be、78e4等截图保持各自指纹，不改标为本版。
