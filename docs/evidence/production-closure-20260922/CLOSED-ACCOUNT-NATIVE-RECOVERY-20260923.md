# 已关闭账号的原生恢复路径（2026-09-23）

登录接口明确返回 `ACCOUNT_CLOSED` / `MEMBER_NOT_ACTIVE` 时，账号页显示对应短提示及现有公开的微信反馈入口，不再把确定的拒绝写成网络结果未知。旧会话在服务端 `AUTH_REVOKED` 后清除，客户端不自动重新打开登录页；管理人员处理其他成员时收到的 `MEMBER_NOT_ACTIVE` 不会错误清除管理人员自己的会话。

本次只修正现有账号页与公共隐私页的路径，不建立第二客服系统。公共隐私页已有微信 `feedback` 按钮；其是否能在当前发布主体和设备上实际到达运营方，仍需原生设备和微信后台核对。它不能被记作已验证的正式客服实收。
