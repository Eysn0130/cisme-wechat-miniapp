# 普通客服记录保留执行补充（2026-09-23）

本批在原 PR22 分支增加现有 Worker 的普通客服到期清理。它只处理已结束、未关联订单或售后、没有有效法律保留的会话；关联交易的客服记录继续按交易类别处理，不能用普通咨询期限整段清除。旧售后案件若没有显式会话外键、但属于该会员，也阻止清理，避免旧数据误入普通路径。

经营方未指定普通客服咨询的统一天数。`support_conversation_policy_pending` 可以单独配置正整数天或月。规则须为 `enforced`、`active` 且 `automatic_purge_enabled=true`，Worker 才会自动执行；新列升级默认 `false`。仅启用人工清理规则不会触发自动批量删除。每次配置变更进入 `audit_log`，记录版本、期限、启用状态和自动执行开关。

Worker 在同一数据库事务中锁定政策、会话和法律保留表，复查资格，排队清理客服媒体，删除消息与会话，并写入不含正文的审计和出站事件。人工清理也按相同锁顺序执行。测试覆盖政策未启用、只启用人工规则、按自然月到期、近期待保留、法律保留、跳过被保留的旧会话而继续处理后续到期会话，以及重复执行。自动执行仍未在 production 启用，未清理真实历史资料。

验证：本批完整单元测试 1248 项通过、1 项跳过；完整隔离集成测试 861 项通过。隔离迁移生命周期、生产基线升级、隐私 schema 清单和现有人工清理用例通过；类型和小程序包体门禁通过。该证据不覆盖生产备份恢复后的删除防再现，也不证明正式用户导出、删除、注销已经实现。当前生产恢复路径仍须在重放独立删除抑制事实后，才可声称历史清理不会被旧备份还原。
