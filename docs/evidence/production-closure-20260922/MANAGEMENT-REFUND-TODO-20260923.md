# 管理端退款待办指向真实操作（2026-09-23）

管理首页原“退款异常待核对”计数包含售后驳回、渠道关闭等情况，点击却只进入资金页默认的**待审批退款**列表，无法按计数找到对象。现改为精确统计 `commerce_refund_request.state='requested'`；具有退款审批权限时，首页“退款待审批”直接进入既有资金页的退款申请列表。授权不符时不出现该计数。渠道异常仍在既有资金异常列表中按原权限处理，不再混为审批待办。

隔离 PostgreSQL 回归补了申请入队、审批后计数减一及撤销权限后不再下发计数；原管理 WXML 模板编译、类型检查与包体检查通过。首页英文工程标题和冗长说明改成短文案。当前原生包哈希另由现行 manifest 记录；模板编译不等于 DevTools 页面状态或真机视觉验收。
