## 可见文案处理记录

这是本轮确定并实施的文案决策；全站每个动态状态的最终计算样式和断行尚需原生逐状态核对。

| 原表达 / 场景 | 决策 | 当前表达或行为 | 理由 |
|---|---|---|---|
| “当前没有可发布的护理邀请”阻断社区发帖 | 改写并改行为 | 直接打开“创作护理故事” | 发帖不是邀请资格 |
| 社区卡片默认“人工审核” | 删除重复提示 | 正式帖显示互动量；审核事实在作者与治理视图呈现 | 不把内部流程当社交元信息 |
| “会员内容暂时无法同步” | 改写 | “社区内容暂时无法加载，请重试” | 账户与内容来源不混淆 |
| “有效邀请暂时无法同步，不能据此判断为无邀请”及同义错误 | 改写 | “活动暂未加载，请重试” | 错误和真实为空仍在数据层分开，用户看清下一步 |
| 客服“上传后由服务端校验”“发送时服务端再次核验” | 改写 | “选择图片后可先预览…”“选择要咨询的订单” | 保留服务端校验，去掉对用户无用的实现描述 |
| 客服“图片已安全校验” | 改写 | “图片已添加” | 避免对安全作绝对承诺 |
| 正式发帖的内容权利与公开同意 | 保留并按需出现 | 创作页提交前两个独立确认 | 公开范围和素材权利影响用户决定 |
| 推荐与佣金 | 保留利益关系披露 | 推荐确认页说明直接关系与真实成交限制 | 不将点击或分享解释为收益承诺 |
| 微信支付、退款、结算状态 | 保留限制 | 尚无真实付款/提现成功界面 | 平台事实和后端状态尚未形成闭环 |

## 验证与复核

本轮在独立 PostgreSQL 测试库执行前向迁移及回滚生命周期。最后一次完整回归：单测 **308/308**，集成 **120/120**；`npm run typecheck`、`npm run build`、`npm run lint:contracts`（40 migrations/73 tables/81 paths/27 events）、33 路由 `miniprogram:package-gate`、`git diff --check` 通过。`design:qa:status` 的清单结构可用，但 `releaseReady=false`：当前源码哈希无 DevTools/真机全路由证据。源码若继续变动，这些数值需要重跑。

独立静态审阅分别检查资金/权限、UGC/隐私、移动交互。资金审阅发现支付与到期竞态、快照虚高风险，现对异常关闭并在隔离测试覆盖；UGC 审阅发现私有草稿直读、乱序安全回调、上传完成竞态，已按当前源码修复；移动审阅发现草稿中断恢复与图片失败重试，已补局部备份、预览及重试。审阅没有使用当前包微信原生画面，因此只构成源码复核。

依赖检查：`npm audit --omit=dev` 报告生产依赖 0 漏洞；完整 `npm audit` 的 4 个 high 位于既有 `miniprogram-simulate` 开发链，需由负责测试工具升级者评估，未因本轮修改生产依赖而开放额外运行时风险。`sharp` 用于审核通过后生成私有无元数据衍生图。
