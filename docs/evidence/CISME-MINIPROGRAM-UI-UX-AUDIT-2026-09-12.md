# CISME 微信小程序全路由 UI/UX 审计

## 执行摘要

当前 27 条原生路由在本地合成数据和已登录开发者工具下全部能进入默认健康画面，Plum/Pearl 视觉和主要导航有较好的连续性。本轮针对共因修复了客服队列的迟到请求与分页生命周期、过长预览、消费者和管理页的工程化文案，并把偏小的全局 micro 字号从 10px 调到 11px。最终源码包与 27 张重新捕获的原生截图、16 张 Composer 状态图及交互证据均绑定同一哈希。总体产品完成度评分为 **6.8/10**：默认首屏已有成熟基础，但全业务状态、真机软键盘/大字/系统能力、真实弱网及正式支付等仍无足够证据，设计 QA 继续阻断发布级验收。

审计基线：`apps/miniprogram/app.json` 的 27 条路由；源码包 SHA-256 `a7a92a2b41ef6a2efcdf3e22401ccfc28152b54604e404f5023472bc7cc6f855`。该值与 `review-composer-a7a92a2b-20260912t0948/source-manifest.json`、27 张原生模拟器截图及归档的 `source-acceptance-a7a92a2b41ef.json` 一致。截图来自本地合成数据、已登录开发者工具，尺寸 484×1048；健康扫描为 27/27，但全状态视觉验收仍为 blocked。以下「视觉」只评价该默认首屏；交互、功能、无障碍、动效和性能以源码静态审阅及已有专项证据为准，未实测项目不记 PASS。

## 当前系统地图（源码提取，未新创品牌）

- 色彩：brand `#56306f`；deep `#321d48`；背景 `#f7f2f8`；半透 surface `rgba(255,252,255,.78)`；主文字 `#352a3a`；次文字 `#75697a`；线 `rgba(78,47,91,.12)`；错误 `#8d3150` / `#f8e8ed`。成功/警告/信息并无足够跨路由同语义样本，暂不硬造 token。
- 字体：展示标题 `Songti SC/STSong` 46rpx；导航标题系统字体 21px；普通正文 14px；主操作 16px；辅助 12px；micro 已由 10px 调为 11px，系统大字仍需真机验证。全局按钮最小触控 44px，主/次按钮 50px。
- 布局与容器：页面水平 28rpx，Stack 顶部为状态栏安全区 + 56px；卡片基准 32rpx，字段 21rpx，pill 全圆。列表先用留白/分隔线表达关系，卡片只用于独立任务或操作组。固定底部需要 `safe-area-inset-bottom`，对键盘仍需真机检查。
- 表单与操作：label、helper、必填/错误与恢复动作在当前页表达；主操作使用现有 `.primary`，次操作用 `.secondary` 或文字按钮。提交中保留按钮尺寸、禁重复，并在失败时保留可恢复输入；字段和底部 CTA 不机械使用同一圆角。
- 图标：沿用本地 SVG 的线性语言，视觉尺寸与至少 44px 可点击区域分开设计；失效、选中及只图标操作要同时有文字或可访问名称。

### Motion system 与可访问性交互规则

保留当前微信原生页面转场，按压反馈优先使用原生 button 状态与轻量颜色/透明度变化；高频轻点原则上 120–180ms，普通状态转换参考 PRD §6.3 的 160–280ms，Sheet 以约 260–320ms 的进退解释层级。当前源码局部还存在 120–360ms 的不同 transition，这一项是**待整合的设计债**，不能说已统一。没有验证持续帧率、减弱动画系统设置或 20 次连续操作舒适度，因此不给 Motion 满分。只有关键成功/警示/破坏性确认在真机证实价值后才考虑触觉反馈；普通导航默认无震动。

按钮继续以 44px 最小触控和 50px 主操作为底线；disabled 必须有相邻原因，loading 维持宽度和 single-flight。状态不可只靠红绿区分：同时保留文字/标识。Sheet 的蒙层、关闭、键盘、焦点回收与可中断性仍需设备级复核。所有输入页在系统大字、长 CJK 和真实软键盘下暂标 `LARGE-TEXT RISK` / `UNVERIFIED—DEVICE`，不把模拟 inset 帧写成真机通过。
