## 关键链（分别标注 DevTools、iOS、Android；不可互相代填）

1. 游客冷启动 `pages/home/index`：确认可见“授权身份并开始”，不被 `onShow` 自动重定向；进入 `pages/privacy-rights/index` 查看游客指引并返回。记录胶囊/安全区、文字、图片、滚动、导航及截图。
2. 会员 A 显式登录、终止并恢复小程序：核当前会话所属、状态加载、弱网/401/403/429/离线的不同反馈；切为会员 B 后，A 的迟到请求/选择器/上传回调不得回填 B 的页面。拒绝隐私权限时，保留无关功能与文字草稿；重授权可恢复。
3. 仅以合成计划周期进入 `planned`，由用户显式确认开始；到期时按 `00 净澈 → 01 清洁 → 02 修护 → 03 精护` 逐步完成，每步在服务端形成持久化事实，提交护理后自我感受；中断/恢复后不得跳步或重复提交。`pages/records/index` 回看每步与感受；旧记录缺详情时明确显示事实缺失，不伪造。
4. `pages/settings/index`：合成地址增删改、微信地址选择、剪贴板识别与授权拒绝/离页/切号迟到回调；禁止后台自动读剪贴板。核键盘、遮挡、安全区和错误恢复。
5. `pages/community-compose/index`：文字草稿、媒体授权拒绝/重试、离页与切号后回调丢弃；公众发布开关关闭时保持草稿/待审，不测试真实公众投放。
6. `pages/orders/index` 与详情/结算：只使用支付关闭的合成订单与异常；核本人/他人对象隔离、列表/详情字段一致、429 不盲目重发写操作，不触发真实付款/退款。
7. `pages/privacy-rights/index`：本人请求及状态、合成资料导出限时/撤销/跨成员拒绝、明确范围的合成自报微信号擦除状态；真实用户导出、删除、注销和撤回保持关闭。记录对外文案与实际可用范围是否相符。
8. `pages/management/index` 及适用子页：无 capability 返回受限，具 capability 的操作审计 actor 来自服务端签名会话；异主体/异对象与双人复核不可由提交的 principal/role 冒用。禁止真实资金及公众 UGC 操作。
9. 运行 `npm run miniprogram:route-audit`，以 `apps/miniprogram/app.json` 的全部 37 个路由为逐页索引。每页按适用身份和 `loading / empty / normal / error / retry / interruption / resume` 记录；不适用项写足够具体的理由。逐页核胶囊、安全区、字号/截断、图片、滚动、键盘、返回、慢网/超时/离线、会话切换；每个 P0/P1 缺陷写 ID 并保持 blocked。

每次操作只在当前包 SHA 和标明的环境下完成。对同一状态保留原始截图/录屏、DevTools 控制台与网络摘要、请求 ID/响应状态（脱敏）、测试账号代号及时间；禁止后处理原图后冒充原始证据。截图前检查是否含个人头像、通知或凭据。需要完整设计放行时，按 `current-source-acceptance.json` 的 route states/evidenceIndex 填写并运行 `npm run design:qa:status`；`releaseReady=false` 就不能标 PASS。
