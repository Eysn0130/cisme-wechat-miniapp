# 社区创作入口与发布闭环 · 2026-11-01

本轮按用户批准，将原中央“＋”生长入口接入真实私稿能力，并完善发布、审核与回访。产品约定见PRD K.8的COMPOSE-FAB-01、COMPOSE-PRIVATE-01、COMPOSE-EDITOR-01、COMPOSE-RECOVERY-01、COMPOSE-REVIEW-01、COMPOSE-QA-01，以及COM-U01/U02、MYCONTENT-01。未启用真实交易或公开UGC，未部署服务器或上传体验版。

当前小程序源码指纹为`6893d140f268cd69f0a2462ca3cc460b625c41effda5702d578fb357238af217`，由现有包检查计算，**不是微信官方上传包哈希**。`final-capture-source.json`记录真实页面及导航四文件分别与独立原生夹具逐字相同的校验。旧截图、旧包与本轮范围不混用；全40页和iOS/Android真机总验收仍为blocked。

## 本轮完成的行为

- 已登录用户进入社区，服务端`draftsEnabled`确认可用后显示原样“＋”；保留420ms生长及符号延后出现。游客、审核模式、过期身份或能力未知时不保留旧入口。公开关闭时入口含义是写本人私稿，提交公开审核仍受独立门禁控制。
- 发布页媒体优先，支持纯文字、纯图片、图文、选填标题、最多9图、首图和排序。输入、进度、失败重试、图片迟到错误及原生相册/预览往返有归属守卫。固定操作区处理安全区；原生正文确认栏用于完成输入，键盘出现时收起操作区。
- AI声明有未选择占位，要求本次明确选择，包含“不明确”的合法选项。私稿保存不要求同意公开；社区公开不捆绑品牌商业许可。服务端验证内容、权利/公开确认、AI确认及媒体，并将主动AI确认写入已有提交审计。
- 新建意图各自使用新编号；同次未知新建保留原编号。保存/提交未知时只读核对同一对象、版本与内容，不自动重发。仍为原版本不能认定原写入失败；允许明确知情保留输入离开，说明离开不会撤销已发送操作。
- 草稿恢复按真实owner/post/version隔离；失败/未上传图片保持失败语义，临时文件失效明确要求重选。系统返回提醒不替代onHide/onUnload备份；不声称原生提醒拦截所有手势。
- 本人列表有服务端状态筛选、总数和游标归属。审核中、待发布复核为只读，成功后可查看本人投稿、返回社区。旧公开版本与新修订分别展示，并结合当前公开门禁描述实际可见性。含已发布版本的修订不能按“未公开草稿”删除；两层读取守卫防止列表过时导致误删整篇。
- 后端禁止覆盖待审/已通过待复核修订；作者有效状态、媒体、双人审核和版本约束在事务内检查。内容锁等待后再按固定顺序锁门禁和审批，用实际数据库时间复验；关闭、过期或撤回后不写公开终态。普通UGC评论批准同样核验可见内容、作者/回复对象及门禁；关门不阻断退回处理。
