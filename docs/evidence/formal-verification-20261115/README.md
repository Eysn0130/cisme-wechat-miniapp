# 正式发布核验补充 · 2026-11-15

本轮原生包修复物流插件的启动依赖，并补齐微信商户平台既有整单现金退款的核对入口；没有发起真实扣款、退款或转账。

## 问题与修改

- iPhone 真机调试捕获 1 个物流插件初始化异常及 1 个插件组件属性警告。长调用栈来自同一个异常。官方插件此前在主包启动时注入；现置于独立的无页面分包，仅在本人订单获得服务端 waybillToken 后通过 requirePlugin.async 下载。异步返回后再次核对页面、会员和包裹，失败仍可复制运单号。没有修改或屏蔽微信插件内部代码。
- 商户平台完成的退款没有本地申请与退款意图，旧接收器无法匹配。新增管理员订单详情“核对平台退款”文字入口；服务端在查询前和落库前分别核对 commerce.money.reconcile，只执行官方签名 GET，仅接受与原支付完全一致、已成功的整单现金退款。部分退款、混合支付与进行中的售后继续走原流程。
- 已核验事实进入现有退款 inbox 和佣金/积分/券补偿链；同步不创建虚假的审批记录，不发送退款 POST，不回补实物库存。退款意图直接是 accepted，崩溃后只能按原单号查单恢复。唯一单号、已有申请和累计金额守卫防止重复效果。
- 退款记录按订单买家隔离，订单列表与详情显示已入账退款的金额及“已退款 / 部分退款”；保留原始支付状态事实。整单平台退款阻止再次申请退款与继续发货。
