# 社区三入口：接口能力与交付边界审计

日期：2026-11-02。范围：核对 PRD K.10、消费者 UGC 服务、当前小程序源码和已归档证据；未访问密钥、正式数据库，未部署、上传或新增真实数据。本文件更新入口改造前的差异记录，只说明当前源码能力及其边界，不新增CISME原生、真实账号或手机验收结论；当前包指纹和截图范围以本目录主线程记录为准。

## 三入口的实际含义

根代理实际查看本机 Rednote 加号菜单，入口为 Choose from album、Camera（副文案 Capture & Go Live）、Text。早期本机相册为空、相机为黑色画面；随后通过已授权品牌图片实际进入图片编辑，已核对 photoeditor、crop、adjust、filters、text、stickers 及 photo-publish 页面，对应 rednote-06..13 PNG。未执行 SaveDraft/Post，已返回 Explore；导入Photos的同一副本已按精确对象可恢复删除并回到空库，清理记录见 rednote-reference-cleanup.json。不能继续将“未进入图片编辑”作为当前事实，也不能由工具可见推定参考应用所有素材和手机表现已核验。

文字制卡与最终发布页已实际查看，长文后续面板在本机出现空白。Camera副文案不构成CISME视频或直播的业务授权。Rednote参考操作和清理证据不属于CISME发布验收。

| 入口 | 当前小程序衔接 | 既有后端承载及边界 |
|---|---|---|
| 相册 | 中央加号先选相册，原生选择仅 `sourceType:["album"]`、最多9张；有效选择后交付新建意图，进入本地图片编辑器确认后上传 | 登录本人私稿；JPEG/PNG/WebP，每张不超过10MB、每稿最多9张；保存、重排、重试、审核及回看。没有自建Rednote最近项目、视频、Live Photos分类页 |
| 相机 | 独立 `sourceType:["camera"]`、单次1张，复用本地图片编辑器；拒绝时按来源指向设置，设置返回须显式重选 | 仍是照片素材链路；真实摄像头、微信原生授权与手机往返须单独验收，不能由本机黑色画面或回调夹具代替 |
| 文字 | 本地文字制卡与直接写正文；3款静态品牌模板、最多300个可见字形，实际Canvas导出PNG；正文沿用5000字 | `mediaIds=[]`且正文非空可保存及提交，标题选填、最长120字。卡片确认后按新图片上传；不新增文章类型，不等同于Rednote长文分支 |

三条路径共用同一草稿对象。`services/community-compose-intent.ts`的本机随机交付编号有效2分钟、同账号同环境、单次消费，URL不含媒体路径；取消、切号和迟到结果不能混入另一稿。有效媒体选择前不创建私稿。原生隐私授权往返与真正离页分别处理，设置返回不自动打开选择器。编辑页内添加内容也明确选择相册、相机或文字。

## 图片编辑、封面与本地处理

`components/community-image-editor`让已选媒体和编辑态单图进入同一本地编辑器：切图、追加、移除、设为首图，以及按能力开放的微信原生编辑/方形裁剪。封面仍是修订中`position=0`的首图，保存顺序后由现有feed取图；没有新增独立`coverId`、独立封面比例或封面裁切框接口。

`services/ugc-photo-effects.ts`和本地Canvas实现了确定性的非AI效果：

- 原图、暖调、黑白、鲜明四档；亮度、对比度、饱和度限制在[-100,100]。
- 本机叠字最多30个可见字形；上方/居中/下方、白/墨/紫；内置Unicode贴纸仅✨、💜、🌼。没有外部贴纸库、模型或内容生成。
- 像素函数复制输入、保留alpha并约束RGB；实际新JPEG导出先铺白底，再绘图片及叠加内容，最长边不超过1440px、质量0.9。透明图导出因此是白底JPEG，不能把helper的alpha保留解释为透明文件导出。
- 导出后重新检查本地路径、真实字节数和MIME；失败保留输入。未应用效果须先应用或明确放弃，不能切图、换封面或继续时无提示丢掉修改。同一编辑会话从原输入重新计算，避免反复压缩叠加。

本地Canvas与微信原生编辑能力分别检测。效果参数仅在当前组件上下文内存，不上传为新字段，也不新增长期非破坏编辑历史。文字卡片模板偏好沿用精确本机备份；图片结果确认后仍须授权新素材、上传和完成校验，后续保存修订与审核规则不变。

编辑态单图只在新素材`complete`成功且账号/稿件/页面/版本归属仍有效后，在原位置替换引用；取消、失败或迟到结果保持旧素材及旧公开修订。此前只读复核发现上传失败会失去当次编辑结果的重试入口；当前源码已增加精确绑定账号、稿件、原素材与版本的本机临时候选，可显式重试使用或放弃，成功完成后才替换。此候选仅在本页内存，不等于跨退出/重启恢复；实际聚焦回归结果以主线程冻结记录为准。未绑定或失去引用的新素材不等于公开内容，沿用既有服务端清理及保留规则。

## 微信原生图片编辑：官方核对结果

此前已核对本地`miniprogram-api-typings@5.2.3`与微信官方正文。官方站点返回HTTP 200，正文经gzip解压后读取；浏览检索工具未能直接打开原站，未将第三方文章当作官方能力证明。项目配置基础库3.15.2，运行时仍检测实际版本及方法。

| API | 最低基础库 | 官方明确承诺 | 不能据此承诺 |
|---|---|---|---|
| [wx.editImage](https://developers.weixin.qq.com/miniprogram/dev/api/media/image/wx.editImage.html) | 2.22.0 | 本地/代码包路径输入，成功回调给出编辑后临时文件 | 参数未指定旋转角度、涂鸦、滤镜、贴纸或统一工具栏；不同平台的工具不能假定一致 |
| [wx.cropImage](https://developers.weixin.qq.com/miniprogram/dev/api/media/image/wx.cropImage.html) | 2.26.0 | 本地/代码包路径输入；16:9、9:16、4:3、3:4、5:4、4:5、1:1比例，新临时文件输出 | 无任意比例、裁剪坐标、旋转角度或非破坏编辑历史参数 |

官方两者均不支持原生Promise调用，也不支持小程序插件。`services/ugc-image-edit.ts`使用成功/失败回调包装，返回`success/cancel/unsupported/error`；成功须为另一条有效本地路径，不接受远程、空或原路径。封装本身不申请权限、不选图、不下载上传、不写相册。调用方负责scope、原生往返、文件校验和新素材替换。类型来源另见[wechat-miniprogram/api-typings](https://github.com/wechat-miniprogram/api-typings)。

此前聚焦结果：`npx vitest run tests/unit/ugc-image-edit.test.ts`为1文件15项通过，`npx vitest run tests/unit/ugc-photo-effects.test.ts`为1文件23项通过。前者证明注入回调/能力/取消/新路径契约，后者证明纯像素与参数约束；均不能证明微信真实相机、原生工具栏、Canvas实际字体/导出或上传已在手机通过。当前新增组件及原生范围按主线程记录单独核验，本文件不把此前测试改标为新包全状态证据。

## 发布、权限与公开门禁

`services/api/src/formalUgc.ts`的`createDraft/saveDraft/submit`保留本人归属、有效账号、版本、媒体引用及禁止隐式覆盖待审修订。按后续PRD K.11，私稿不要求内容权利／公开开关，缺省新私稿两项元数据为false；本人对当前版本提交且内容、媒体及末端真实门禁通过后，原子追加publicConsent=true的待审不可变快照及publish_action来源审计，rights原值不伪造，旧修订不改。提交仍要求正文或至少一张图，公开仍经内容安全与独立复核。K.9移除的普通消费者AI控件及强制条件不恢复，历史字段/审计事实保留。

对应`services/api/src/server.ts`的创建、保存、授权/完成媒体、提交、本人列表/详情、审核及独立复核路由均沿用。`authorizeMedia`只接受JPEG/PNG/WebP并写`kind=image`；基础表预留video和video/mp4不代表消费者视频链路可用。后台`reviewMedia`自动旋转、缩放、转WebP、生成详情和缩略图属于审核衍生处理，不能冒充消费者编辑器。图片编辑和文字制卡复用现有新素材链，不需要新增后端内容类型；独立编辑参数、原输入/结果长期关联仍没有专用接口契约。

PRD`COM-U01/U02/U03`、`COMPOSE-PRIVATE-01`、`COMPOSE-REVIEW-01`、`COMPOSE-FLOW-01`和K.10约束自由图文、私稿、独立修订及真实公开状态。§6.2排除短视频；§6.6.2公开准入和审核人力条件未因视觉复刻或删说明文字取消。`GET /v1/ugc/status`分开私稿与`publicEnabled`；公开读取、提交和末端发布仍检查开关及有效审批，安全结果需真实确认，作者不能自审，公开须另一审核员复核。未读取实际部署秘密或远端配置，不推断线上当前版本或门禁已开。

消费者视频、直播、音乐、话题、@提及、投票、位置、链接标签不在本轮图片/文字范围，不画无真实业务按钮。品牌精选视频由`editorial.ts`和`ED-BRAND-03/04`单独管理，不能借其播放证据宣称消费者视频可用。Rednote长文后续仍未验收，CISME5000字正文不计作长文功能交付。
