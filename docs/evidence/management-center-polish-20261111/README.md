# 管理中心精修与发布核验 · 2026-11-11

本轮将原生管理中心改为待办与分组入口，精修13个management路由及售后、精选评论共15页。保留CISME品牌，统一字号/数字、间距、状态和44px点击范围；辅助操作去外框、筛选使用选中线，主提交保持品牌色。没有增加依赖或改成Web管理产品。

主要修正：

- 积分单权限不再出现“暂无入口”；商品列表绑定当前账号/context、已读对象和分页快照。
- 会员/全局费率填写与提交统一北京时间，拒绝无效日期；库存可录入负数出库。
- 积分未知结果沿用原请求重试并锁定原载荷；更换身份后清理原管理命令；补齐提交前校验和规则展开。
- 财务待办可按订单查看权限进入原单；切换账号/context和返回的旧确认不能沿用旧财务快照。
- 资质、上架、库存、支付、物流/微信同步、收货、售后质检、退款和隐私执行仍分别核对；保留版本、审计、幂等、内容安全和另一人复核。
