## 问题与修复

HTTP 预检查可以在另一个未提交的封禁/撤权事务期间看见旧权限。此前报价/下单/取消、本人订单/退款/结算历史，以及管理订单/退款/履约/资金异常/账单列表可能继续返回 200 或写入新事实。

新增事务内 active member 共享锁；需要 capability 的读取在同一事务内调用 `requireWithClient`。列表计数和内容保持同一 REPEATABLE READ 快照；详情按需读取本人或管理脱敏地址。写入在请求键重放前复核状态；拒绝时不得增加报价、订单、退款请求、审计、Outbox、退款意图或渠道退款。

通用授权以前用事务开始时冻结的 `now()`，且 SQL 谓词可先于行锁等待执行，导致等待期间过期的 grant 被放行。现在锁后再以数据库 `clock_timestamp()` 检查该 grant 的 expires_at。此处证明授权检查时的有效性，不声称将时间到期冻结至后续任意外部动作完成。

没有改变正式新支付/退款/转账或生产履约准入；没有移除隔离门禁，也没有将测试发货政策作为正式售后规则。新资金关闭时仍可读取授权范围内的历史记录。
