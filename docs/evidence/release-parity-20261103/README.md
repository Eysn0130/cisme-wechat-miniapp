# 正式候选功能接通：范围修订与消息回调准备

用户最新要求体验版为正式版准备，打通当前PRD已生效范围的完整功能，取代此前按环境名称长期关闭交易及公开UGC的限制。AGENTS.md和PRD RELEASE-PARITY-01至04已同步；用户随后澄清微信消息推送尚未配置，并要求提供配置由本人操作。本记录不把较早“已经配置”的回答当作当前事实，也不自行进入被浏览器安全策略阻止的微信公众平台。

当前服务器只读基线见runtime-baseline.json：体验源97ac/schema106，正式源dbd2/schema97；两环境均有3个legacy_preview商品但没有已发布商品。正式配置已引用商户、交易恢复及履约材料，本地密钥、证书绑定和有效期、信任公钥及有期限的独立能力记录验证通过；这不等于已向微信核验商户绑定、接口资格或真实交易。体验环境不复制这些正式材料。手机号、积分规则／抵扣与普通公开UGC的真实启用证据分别核对，不能以一项通过推断全功能已接通。

本轮修正两个具体源码问题：一是URL配置验证与密文业务推送混用，配置安全模式后正常的token签名GET验证会失败；现在签名GET和密文GET均可验证，POST继续要求安全模式密文，禁止坏密文回退，响应不缓存。二是积分规则配置强制包含已退休的CARE_D7_STORY_R0；移除这项过时依赖，规则数量、有效期、财务依据和独立复核等正确约束保留，不重新启用任务投稿或生成积分。

新增trial-message-callback-update.py沿用已部署97ac的完整来源、私有输入、独立数据、生产保全和加密保护点。仅允许同106份SQL、同依赖树的应用更新及追加微信消息Token／AESKey／检测素材基址三项配置；不执行迁移、不修改业务开关、商品、资金、会员同意或原有业务事实。密钥只在服务器生成，私有配置文件不入Git或公开日志。默认预检只读，执行时先排空两个体验服务并保存可验证加密保护点，异常保留现场并停止服务供前向恢复。正式服务不切换。
