# 0.1.27 真机社区启动失败修复

手机上的社区完全空白（连静态标题和分类栏都不显示），用户提供的 vConsole 首条错误已确认：`services/following-feed.js` 未定义，在载入 `pages/community/index.js` 时 require 失败。后续 `wx://not-found` 很可能是页面创建失败的连带错误，不将其另行当作已证实的组件配置缺陷。原始技术信息经最小投影保留在 `reported-phone-error-027.json`，绑定此前0.1.27交付源码；没有提取手机二进制包哈希。

最小打包修正位于 `apps/miniprogram/project.config.json`：显式关闭 `ignoreUploadUnusedFiles`，通过 `packOptions.include` 保留 `services` 公共模块目录。发布前包检查拒绝恢复自动剔除或遗漏公共目录。除关注模块外，同时保护本版新增的 `read-presentation`（帖子、作者、商品等页面展示连续性）和 `retired-task-proof`（已移除投稿证明的旧链接返回）。源码存在不代表上传包内模块已注册；发布采用独立、全新、不可变的编译目录，逐字节核对与主目录源码包哈希相同，避免沿用开发工具原项目的旧编译状态。公开SDK中自动过滤的实现、原生Skill字段说明是打包策略依据，但尚未从0.1.27手机二进制中独立证明是哪一层过滤／缓存遗漏了模块。

此前候选还修复了已执行复现的社区读取问题：精选已返回时等待附属权限或其他列表、首次读取重复提交空列。现在精选卡片、数量和就绪状态一次提交，所有只读订阅随页面取消，并核对身份、环境和读取代次；权威失败仍清除旧内容。双列改用稳定列标识及独立卡片别名。旧模板在JS WXML渲染器的单独对照同样通过，因此不将列标识推断当作手机整页空白的已证实原因。对应PRD `COMM-FOLLOW-04/05`、`COMM-DIRECT-PUBLISH-05/06`。没有改动关注／发布接口、底栏样式、图片批次或后端。

交互约定：同身份返回保留已确认卡片并刷新，已返回精选立即可读；切换身份／环境清空旧状态，离页响应不更新隐藏页；失败提供原生重试。点击路径、触摸范围、aria标签和动效偏好沿用现有实现。没有新增用户数据采集。

当前原生源码包为301文件、40路由，SHA-256 `3a468032033f11850684d76480e431f810c1f46a86be6915f3cd8c0916bcc4eb`。3059项单元测试通过，1项既有跳过；两端类型检查、包检查、40路由源码审计、官方WXML／WXSS局部编译通过。详细检查结果见 `validation.json`。官方模板／样式局部编译及本地真实源码依赖注册均只证明各自检查范围；原生上传成功也不等于手机验收通过。完整40路由全状态及iOS／Android真机矩阵保持blocked，旧截图保留原始源码范围。
