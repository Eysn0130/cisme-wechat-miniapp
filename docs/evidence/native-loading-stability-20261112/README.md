# 原生页面切换、加载稳定性与预热

本轮从体验版 0.1.42 / main c5c1a142 开始，按 NATIVE-LOAD-01～05 做最小修复。当前原生源包为 `30713a080bdbab50030bd34161ea471d9d339074cf87dfb89a544dbfbc44ba3d`。全 41 个注册路由、共享请求/导航/头像/图片/定时器均完成源码排查；静态清单是 `static-route-audit.json`，不代表全状态实机通过。

## 实施结果

- 商城和商品的刷新提示从正文流移到既有图片区域，复用原有无阻挡加载指示；正文、商品卡与规格入口在刷新时保留位置。商品图序计数与加载指示分别位于两侧，真实错误和重试仍可见。
- 商品按 code 直接查询单件详情，减少目录载荷，避免未来商品排到目录首 20 条以外时丢失购买绑定；同 code + admin 来源校验仍有效。现网目录 2449 字节、单件详情 1143 字节，仅用于说明当前响应规模。
- 商城与商品的 GET 绑定页面生命周期，离页/卸载/新读取取消自己的订阅；其他页面共享订阅继续，独立写命令不被取消或重发。价格/库存/积分/权限继续重新核验，没有新增 TTL 数据缓存。
- 帖子头像与首图测量并行；保留 ED-MEDIA-01/02 首图确认尺寸后呈现、2.5 秒有界回退与迟到守卫，避免先铺图再改变比例。
- 13 个触发页配置下一跳代码分包预下载，大图商品包仅 Wi-Fi；同一来源包所有触发规则按去重总量验证，主包目标合计 1,991,055 字节，小于平台 2,097,152 字节上限。预热不打开页面、不创建账号、报价、订单或分享归因。Android 下一 WebView 使用平台空闲 auto 策略；不添加导航延时。

快速离页、迟到响应、商品核验失败与显式重试见 native-interruption-*.json。单元测试执行实际 RequestCoordinator、API、commerce 与 pageRead，核验共享取消、后续价格重读、写命令独立、商品目录外直达和品牌来源绑定；原生模板测试保持节点和选择，并发头像/首图及现有媒体、账号/权限、支付幂等回归继续有效。全量测试及 CI 记录见本目录验证回执。

全部原生验收使用官方微信开发者工具、canonical 项目与精确源包；HTTP 全量拦截，虚拟存储与合成会话，不读取或写入真实会员资料。测试结束恢复原页面、无会话状态、机型、原 wx 方法与 globalData；相关过程留证，不清理真实用户数据。

`public-api-timings.json` 是开发 Mac 到 staging-api.cisme.cn 的 9 次真实匿名 HTTPS GET，全部 200，用于排除本轮可见公共接口阻塞；不是微信真机冷启动、帧率或 P95。模拟器分包本地可用，也不能证明设备实际预下载耗时。全 41 路由的 iOS/Android 物理设备、弱网、字号及完整状态矩阵继续 blocked，见 current-source-acceptance.json。

## 官方依据

- [分包预下载](https://developers.weixin.qq.com/miniprogram/dev/framework/subpackages/preload)：按页面触发、网络策略和同一来源包的 2MB 共享预算。
- [页面切换性能](https://developers.weixin.qq.com/miniprogram/dev/framework/performance/tips/runtime_nav)：Android handleWebviewPreload=auto 等待渲染空闲，SDK 2.15.0 起支持，其他平台忽略。

本轮无需服务器部署或数据库变更。既有正式商户、库存、权限及环境隔离均未变更。后续商品大图或分包增长须继续通过预算测试；尚未完成的真机性能矩阵单独验收，不靠旧截图或静态扫描声明通过。
