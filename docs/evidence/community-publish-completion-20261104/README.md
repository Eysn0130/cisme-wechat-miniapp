# 社区发布完成后直接进入详情

用户反馈发布后仍显示“当前公开版本仍在展示”，要求点击“查看当前公开版本”才能查看。只读检查确认体验 `/v1/ugc/status` 已为 `publicEnabled=true`、`draftsEnabled=true`；问题在编辑页收到真实发布成功回执后没有完成导航，旧版本说明也仍占据成功状态。本轮对应 `COMPOSE-PUBLISH-RESULT-01` 至 `03`。

修改仅涉及原生社区编辑页：当前本人提交确实发布成功后自动进入帖子；从同一详情进入修改时返回并刷新原详情，避免重复叠页。待安全检查完成时仅前台有界读取当前本人、环境、帖子和 revision，离页暂停，返回恢复。检查失败或状态变化不打开旧公开版本冒充新版成功；存草稿、普通打开已发布稿编辑、切换身份与迟到响应均不自动进入详情。导航失败保留已发布事实，重试只重试导航。

最终小程序源码哈希 `4b15f841376982594aa3f34e25788ce0c0bdaa680269dfd7a2ca9b3f2b7b7cc9`，304 文件、40 路由。全量单元测试 3110 通过、1 项既有跳过；首次全量回归仅原生按钮清单未随新增结果重试按钮更新，原结果保留在 `unit-before-action-inventory-update.txt`，同步清单后全量通过。类型检查、包预算、路由与接口契约检查通过。

微信开发者工具实际点击与输入验证了 390px 下六个状态：编辑器、立即发布详情、自动安全检查等待、自动继续进入详情、编辑后返回原详情、导航失败与只重试打开。独立验证工程仅替换 `app.ts` 合成传输与 `app.json` 入口，其余 302 个文件与上述源码逐字节一致；不访问真实 API，不新增真实会员帖子、关注、同意或授权。图像与工具回执见 `native/`，图片原始来源及哈希见 `native/validation.json`。验证工具首次读取时模拟器尚未编译，编译后正常；一次文本读取返回字符串，与验证脚本原先按对象解析的假设不符，修正脚本后从已发布详情继续，没有重复发帖。
