## 移植与恢复边界

原有中央加号样式与生长动效保持。发布页改为原生横向照片条，常规宽度86px、窄屏82px、大屏88px；首图、添加、移除、进度和重试保留。排序仍用两列与明确前后移操作。标题正文更连贯，计数及无障碍标签保留。声明继续明确展示。公开关闭或未知时，突出可执行的私稿保存；开放时才显示窄保存、宽提交审核。

本轮补齐的业务边界：

- 审核中/待发布复核优先远程预览、本地图片兜底；缩略图与点击大图的来源顺序一致。返回后补取中断的预览，旧图片错误不能清除新图。
- 查看公开详情后，按账号、环境代次、帖子、作者和页面重新核对。已删除或下架时，未保存文字、图片与原备份版本仍暂留本页，只读展示；不会继续提供不可能成功的保存。
- 下架内容的未保存修改不因后台返回被覆盖；需先保留这些修改、重新打开后再按最新服务端版本申诉。
- 已删除/下架的未保存修改不能从投稿列表找回。页面与离开确认明确说明这一范围，文字可以选择复制、图片可以预览；不把旧版本备份存在等同于产品内可恢复。
- 未知保存结果读到删除/下架时，同样保留输入并转入只读；异步退出核对之后再次检查终态与归属，不能由重载覆盖本机内容。
- 公开详情删除超时/5xx时只读取一次本人状态；精确编号、作者及deleted均吻合才确认返回。其余明确为结果待确认，不自动再次删除。
