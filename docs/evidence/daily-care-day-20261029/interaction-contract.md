# 个人资料与每日护理修正

范围：PRD 附录 M。原生微信小程序；延续现有紫色品牌、字体和 token，不引入 Web 组件库。`mobile-ui-ux-designer` 负责状态与操作，Taste 只辅助审阅层级、间距、动效和自然文案。

## 资料与状态

设置保存成功采用该次服务端姓名及资料版本，立即同步“我的”和护理页。头像本地文件处理独立；同一会员的较新版本不被旧响应覆盖。首次登录的昵称填写使用原生 `input type="nickname"`，由用户主动选择或输入；不从 `wx.login` 或开发者登录资料推断。微信的官方类型定义是原生实现依据：https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.component.d.ts 。官方网页本次读取失败，不声称已查阅完整网页行为说明。

“我的”顶部保持姓名、已确认的护理状态、下一步入口三层。日常资料读取独立于积分、客服及周期资料。日常读取失败不显示“未护理”；周期为空不再代表没有日常护理。真实周期存在时保留其阶段语义。

## 操作与恢复

| 操作 | 条件、结果与恢复 |
|---|---|
| 今日首次记录 | 读取服务端日期后进行完整四步和感受，明确保存；成功后仅一份当天记录。未确认加载结果不能开始写入。 |
| 调整今日记录 | 按当天记录 ID 与版本明确更新；并发、过期日期或对象版本变化时重读，不悄悄另建。未知结果仅重试原意图。 |
| 展开删除 | 左滑露出 72px 操作区、右滑收起；一次只开一行。12px 方向阈值、横向位移超过纵向 1.3 倍才认定横滑。纵向滚动优先；滑动结束不同时触发详情。 |
| 无需手势删除 | 详情内同一删除操作，触达至少 44px。周期事实不显示该操作。 |
| 确认与撤销 | 删除确认后移出当前列表；保留明确撤销入口。撤销只作用于原 ID/版本，同日已有后来记录时拒绝覆盖。 |
| 断网或迟到 | 不把未知回执当成功；保留一次操作的稳定编号供显式核对。页面隐藏后不弹旧提示；身份变化清除旧资料和撤销对象。 |

沿用已存在的 `sheet-dismiss`、护理卡片和按钮 token。滑动仅使用 transform，手势中关闭过渡，结束后短时吸附；系统减少动态效果时取消非必要过渡。大字号下删除文案、确认框、撤销入口和详情底部应完整可达。颜色之外还使用文字表明状态。

## 记录页首屏与阅读层级

档案首屏按内容和系统字号紧凑布局，不沿用固定222px高封面；标题与可操作控制按真实微信导航尺寸避让胶囊，不靠空白垫高。统计使用已确认的服务端事实，读取中或失败不填成零。

功能文字使用系统sans，主要标题20、次级标题18、正文14、次要12、微文11作为默认字号，以rem跟随系统设置；品牌字标保留品牌字体。记录详情只呈现用户需要的完成日期、四步和感受，不再铺陈内部方案／协议版本行与泛化免责声明。服务端方案版本、历史事实、导出与隐私规则继续保留。删除后的撤销入口优先，避免与“暂无记录”重复提示争占空间。

## 验证边界

原生截图与实际操作绑定最终源码包；旧截图、单元测试和数据库回执分开归因。85f保存与fa5删除／撤销只保留各自的历史动作事实；用户拒绝的3a宋体和768中间截图均不作为后续紧凑页头的最终视觉通过。相同TypeScript哈希只能说明逻辑连续，不能继承模板和样式验收。隔离数据库验证同日并发、版本、午夜、失去回执、删除恢复、先前隔离事实、导出、注销和保全释放。体验账号先保留只读基线，不新增软件假护理；可恢复的删除实测结束后核对本人原始护理内容和后来记录。真机触控、键盘和有真实周期资格的正向路径未经本轮实际验证时继续列为未验。

## 全部按钮的代码复核

用户进一步确认：左滑仅露出独立胶囊，不能直接删除。保留72px展开区，胶囊64px宽、最少44px高，点击才弹确认；大幅滑动、取消和误触均不得产生写入。

参考 [Open Claude UI 按钮源码](https://github.com/Caho1/open-claude-ui/blob/main/code-examples/CdsButton.tsx) 的状态分离及轻量反馈，并翻译为当前微信原生样式。该仓库的 React、Tailwind、Framer 与桌面尺寸不引入小程序。公共动作文字用相对行高配合居中布局，按压仅 opacity 或轻微 transform，减少动态效果时直接切换。CISME 色彩与触达 token 保留，删除使用现有危险色。

代码复核逐个登记原生 button 及非 button 点击入口，分别审消费者与受保护管理分支。全局样式预算保持8192字节；新公共反馈加入后仅压缩已触及按钮规则的空白，PostCSS AST等价校验通过，没有调大预算。管理入口中两处成功后持续busy的确定问题已修复；这属于源码与合成页验证，不代表当前会员获有相应管理权限或已执行真实费率操作。

当前最终包已完成375宽（字号16/26）及390宽（字号16）的局部原生复核，11张当前页面截图经独立阅图；完整左滑仅展开胶囊，取消不改变记录，删除后撤销恢复原事实。0.1.13已通过官方工具上传，并取得同一原任务的成功回执；此次客户端／文档收尾不重新部署体验API。局部软件验收不等于全40页状态矩阵、物理真机或正式公开发布通过。
