# 日历记录页

用户已从五套同尺寸原生预览中明确选择第一套日历版。本轮将该方案接入真实记录，保留上一轮修复的手势、同日单份记录、版本确认与可恢复删除。不恢复旧原型的连续天数、趋势百分比或演示护理。

## 页面与操作

短品牌头部、跨头部与浅底的本周日期卡、最近记录卡保持已选择的层次。使用现有原生导航尺寸、胶囊避让、系统功能字体及相对字号；日期可操作区域至少44px，小屏允许日期条横向滚动，不压缩为不可点的小格。减少动态效果时关闭非必要过渡。

| 状态或操作 | 行为 |
|---|---|
| 最近记录 | 默认展示已加载的本人记录，保留原游标分页与真实统计。日期筛选不覆盖完整记录集合。 |
| 本周日期 | 以同一首屏响应的服务端日期计算周一至周日；记录点直接来自真实careDay。今日、选中与已记录使用不同可见形状和读屏含义。 |
| 选择日期 | 点击已知的过去或今日日期，只筛选下方当天0或1条记录，不启动护理、不补写过去日期。未来与尚未确认覆盖的空日期不能选择。 |
| 当天无记录 | 明确显示所选日期无记录，提供返回最近记录；不误称没有任何护理记录。 |
| 返回最近记录 | 清除日期筛选并恢复完整已加载列表。切换筛选终结旧行手势，迟到触摸不能重新打开不可见行。 |
| 加载或失败 | 保留已确认记录和旧日期信息；失败明确标为未更新，不把读取失败绘成全部未记录。恢复后重新建立本周覆盖。 |
| 跨日或失效游标 | 分页响应日期改变时弃用旧游标链，从首屏重读。无效游标同样恢复首屏；普通网络失败保留原读取意图，避免静默无限翻页。 |
| 删除与撤销 | 已确认回执立即同步列表、日期标记及筛选结果；不依赖随后读取成功才反映结果。未知回执仍显式核对。取消不写入；撤销作用于原ID和版本，不覆盖并发新记录。 |

## 事实与边界

服务端现有接口按完成时间及稳定ID分页，每次最多20条。首屏链确认覆盖到本周开始，或已无下一页时，才把缺少日期标为未记录；已加载的确切记录仍可据其日期显示。旧游标在跨日后仍可能有效，因此不能把其尾页当作新周已完整加载的依据。

新增日历、选中日期及覆盖状态只在本人页面内存中派生，不新增服务器资料、第三方接收方、持久化缓存或权限。切换身份、401及403按现有授权边界清除。没有真实护理周期时不展示周期进度；日常记录与周期记录仍各自采用原事实语义。

## 验证

覆盖周一、跨月年、服务端与设备日期不一致、分页未完整、跨日旧游标、无效游标、失败恢复、日期筛选、返回最近、确认删除及撤销后刷新失败、离页与换人等行为。当前源码重新计算包哈希，原生核对正常与大字号、日期触达、胶囊及底部安全区、滑动与点击仲裁，保留同状态、同尺寸证据。

真实账号操作前保留只读基线，恢复可撤销的原记录后核对事实不变，不创建软件假护理。候选预览、离线页面测试、当前源原生操作和物理真机结果分别归因；本轮局部验收不能推定全40页状态或真实周期正向流程完成。体验API已部署的schema101保持不变，本次为客户端交付。

## 昵称一致性补修

原生复核发现，首页冷启动虽取得真实昵称，定时问候和步骤重绘仍可能因共享资料缓存尚空而退回品牌名。首页现在只在同一身份的页面内存保留已取得的姓名与资料版本；更高版本的设置结果优先，切换身份、失效会话及卸载页面时清除。此修正不发布缺失头像的完整资料、不新增请求或持久化记录。
