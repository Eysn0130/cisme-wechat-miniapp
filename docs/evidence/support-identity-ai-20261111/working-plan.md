# 客服身份与AI闭环排查

用户要求：新用户/管理员两端头像、资料、消息归属、人工申请和回复、商品咨询、AI能力与提示词完整核验并正确修复。

已确认的问题：用户自己的头像未展示；管理端会员头像固定占位；所有历史人工回复使用当前接待人名称；消息分组只按角色可能混合不同客服；AI护理知识仍是旧的日常四步流程，且缺当前已发布商品事实。

最小实施：扩展既有消息/分页的发送者展示信息，服务端按实际principal解析并批量查询，opaque key不授予权限；每页头像去重，客户端仅把本地头像路径写入setData。两端补齐自己及对方头像、姓名和错误回退，按真实sender分组并阻止旧会话/旧账号资料回流。AI护理知识同步当前PRD，已发布商品与规格/价格作为每请求独立的只读知识输入；原有人工路由/版本/回复目标/未知结果守卫保留。新增字段可选，兼容旧服务；不新增表或改会员资产。

验证：身份、角色、私有资料权限、分页、不同客服、头像失败/更新/切换账号、AI与人工竞态、商品来源/资料缺失/注入、隐私脱敏、超时与限流；全量CI；原生双端受控场景；必要时用纯合成内容验证真实模型，未实测不声明通过。用户已有真实会话不作为试验场。
