# 客服身份、人工协作与AI商品知识修复

范围：原生小程序用户客服与移动管理客服、发送者展示身份、当前护理/商品只读知识。未新增表、迁移、业务写工具或权限；不改旧聊天归属、消息内容、会员资产和公开同意。

已修复：
- 新用户进入客服后直接读本人资料；用户及管理员自己发送的消息补齐头像。管理端会员头像不再固定占位。
- 每条人工回复由实际 sender_principal_id 映射 canonical 微信会员及客服别名，不随当前接待人更换姓名；不同客服不合并为同一组。AI保持独立品牌身份，未知旧人工身份中性回退。
- 批量解析并按发送者去重头像，渲染仅传本地图片路径；资料版本倒退、账号/会话/话题切换、删除和图片失败有独立处理，加载失败不影响对话。联系人等扩展资料继续独立鉴权并审计。
- AI知识与当前三款多选日常护理、当日调整、胶囊记录入口及生日建档位置对齐；不恢复弃用历史入口。自动答复和人工AI草稿接入每请求独立的已发布商品快照及内容哈希引用，不读取个人订单或私人资料。
- 对主动提供的订单号、运单号、微信号等明确标签补充脱敏；保留原有限流、超时、短答、完整JSON校验、人工事项分流、回复对象/版本校验与稳定重试。

验证：全量单测3240通过、1项既有跳过；TypeScript、合同、包体与路由结构通过。新增服务端身份/权限/多客服回归及商品知识并发引用校验。本机Docker镜像有磁盘读取错误，数据库集成验证以CI独立数据库结果为准。原生受控场景使用合成身份和JPEG缩略图，全HTTP拦截，不发送真实消息；资料回包是实际平铺结构，冷启动不依赖资料页缓存。

`native/interim` 为修正头像图片尺寸覆盖前的诊断资料，不作最终源码验收。最终原生截图/事实与编译见 `native`，绑定 `package-source-final.json`；模拟器截图不能代表真机或完整接口验收。41路由全状态、iOS/Android真机与大字体覆盖仍未完成，全局验收manifest保持blocked。

实际运行部署、CI与体验版回执在本目录单独记录；没有回执不声称已部署或已发布。正式环境的历史升级和微信公众平台提审缺口不因本次修复自动消除。
