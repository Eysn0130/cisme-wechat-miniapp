## 源码与业务结论

本轮沿用 PRD `SUPPORT-AI-01`、`SUPPORT-HANDOFF-01`、`SUPPORT-FAILURE-01`。普通新会话保持 `ai_active`，包含文本、订单卡片、图片授权/发送和 Provider 不可用场景。复杂问题、低置信度、模型超时或输出不合格只保存短系统提示，返回 `handoff_suggested`，不采用不可信模型正文，也不自动生成 `waiting_human` 或人工申请事件。用户明确申请后才进入等待状态；重复申请事件唯一。

用户消息先提交，模型调用不持有数据库事务连接；生成后再校验有效会员、会话状态与版本。人工申请、新消息或接管可使迟到 AI 失效。既有等待/人工接待、管理员权限与回复、历史订单专用处理路径、幂等回执和提交后故障恢复均保留。打开记录的 GET 不创建问候消息；欢迎语属于本地展示。

管理接口保留全会话列表，包含 `ai_active`；看到 AI 会话不表示用户已经申请人工。原评估脚本曾误把不存在的状态筛选当作真实过滤，原失败回执保留，未通过放宽断言掩盖。
