# 管理页游客登录恢复

游客直接打开客服工作台或隐私请求列表时，页面在请求权限之前抛出本地 401，停留在无法恢复的重试页。现在复用已有登录入口；显式重试可以再次登录，已登录账号继续通过原有服务端能力核验。

范围：两个页面的登录恢复；无样式、服务端权限、会员资产或资金逻辑变更。

## 验证

- 32 项相关生命周期、撤权和读取归属测试通过；新回归覆盖游客不会读取权限/私有队列、不会启动轮询、显式重试恢复登录。
- TypeScript 检查通过。
- 官方微信开发者工具原生检查：两个入口均进入登录页；登录页返回可进入公开社区，Console 错误/警告过滤无匹配。
- 截图来自独立验收工作区；其开发/预览域名仅改为正式 API。主包和验收包哈希分别记录，未将不同哈希或旧截图标为当前全状态通过。截图无会员资料。
