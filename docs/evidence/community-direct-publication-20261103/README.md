## 实现及边界

- 普通帖子点击“发布”后立即启动自动安全检查。安全文字可在本次操作中公开；图片通过已验证的异步回调后，自动生成原有尺寸的公开图片并发布。没有人工审批、图片人工审核或另一名发布者的步骤，不伪造人工审核记录。
- 自动发布只认可当前作者明确提交的版本、匹配文字／图片哈希的 `wechat_v2` 检测事实及仍有效的公开门禁。风险、需核对和检测错误均不能公开，页面保留内容并允许修改。自动动作使用独立的 `system:ugc_safety` 操作者和审计原因。
- 发布中显示真实状态，可刷新或修改；修改产生新的私人版本，迟到的检测不能公开已被替代的意愿。已存在的公开版本直到新版成功发布才替换。旧待审内容标为“待重新发布”，保持私人状态，需作者重新确认发布，不会在升级后突然公开。
- 任务、发布证明、审核进度、补件、旧领奖审核及旧发布复核的业务实现已删除。三个原生旧链接只保留返回社区的兼容处理；社区与“我的”活动入口、D7 完成后的邀请、审核队列和管理台旧操作一并移除。旧写接口返回 `410`，旧队列返回空列表，旧排队发布事件被明确抑制。
- 已有护理记录、积分账目、公开内容、授权、隐私权利和审计历史没有删除或批量迁移。客服图片沿用共享上传通道，其授权、完成及本人读取保持原规则。评论、资料管理、发布后举报／下架／申诉，以及资金的独立规则保留。此前关注频道及页面稳定性修复继续保留。

没有新增依赖、业务表或用户资料字段。唯一数据库迁移 `202611030001_direct_publication_lookup.sql` 为已有审计事实增加查询索引，避免个人帖子状态和自动发布扫描无关审计历史。迁移集合与微信 API 引用清单已更新；没有改动现网开关、既有数据或凭据。
