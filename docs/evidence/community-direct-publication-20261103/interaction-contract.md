# 直接发布交互约定

| 状态／触发 | 行为与恢复 |
|---|---|
| 草稿 | 仅本人可见；存草稿不产生公开意愿，允许继续编辑。 |
| 点发布 | 先完成已上传内容保存，再提交当前版本的公开意愿；操作期间防止重复点击。 |
| 自动检查完成 | 文字与图片证据都匹配、账号及门禁有效时自动公开；成功后才显示“已发布”。 |
| 图片检查进行中 | 显示“正在发布／安全检查完成后自动公开”，可刷新状态、修改内容、查看自己的帖子或返回社区。 |
| 修改发布中的内容 | 按版本保存新的私人修订，取消旧意愿的适用范围；旧回调不能公开新稿或旧稿。 |
| 检查未通过或未完成 | 保持私人；已有公开旧版仍保留。保留文字和图片，显示修改重试提示。 |
| 发布门禁关闭 | 仍可保存私人草稿；发布不成功，不新增公开版本。 |
| 旧待审记录 | 显示待重新发布，不要求人工处理；作者可修改后重新确认发布。 |
| 旧任务／证明／进度链接 | 直接返回社区；导航失败有明确重试入口，不读取旧私人证明。 |
| 离页、换账号、迟到响应 | 维持原请求归属和版本保护，不能覆盖新页面或新账号。 |

复用现有原生按钮、草稿、状态卡及导航；没有增加弹层、第三方组件、推送或公开发布开关。截图中的合成内容仅供验证。
