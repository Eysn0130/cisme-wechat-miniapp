## 完成的行为

需求对应 PRD V2.1-R4 的 `COMM-FOLLOW-01` 至 `COMM-FOLLOW-05`。

- 「关注」固定紧邻「精选」，复用相同文字、选中下划线及原生按钮样式。390px 模拟器中两个按钮的点击区域均为 46 × 44px。游客可以看到入口，主动点击后进入既有登录路径；登录成功回到关注，取消登录保留精选。
- 使用账号的持久化关注关系读取动态。精选作者和普通帖子作者的关注状态统一读取，取消关注同步移除两处可能存在的关系，不修改作者的真实会员身份。
- 新增鉴权接口 `GET /v1/me/community/following`，按发布时间统一排列已关注作者的精选、正式普通帖子及兼容旧投稿。使用全局游标分页，同一作者的重复关注关系不产生重复卡片。精选不作为关注为空时的替代内容。
- 进入、返回和下拉刷新读取最新事实。作者之后发布的新公开帖子进入第一页；分页期间新发的帖子由下一次刷新显示，避免插入当前已读分页。没有增加实时推送或自动滚动。
- 继续执行审核、发布、可见性、作者状态、屏蔽和公开 UGC 门禁。草稿、未关注作者、已下架或撤回内容不进入动态。公开 UGC 关闭时只显示已关注的公开精选，未开放发布权限。
- 同一账号刷新保留已确认的卡片或空状态，不插入挤动布局的加载文字。请求失败显示重试提示；分页保持已有卡片。账号、环境或权限变化时清理不再有权展示的内容，离页和过期响应不能覆盖当前频道。

复用现有原生样式、请求管理、关注关系表和发布规则；没有新增依赖或数据库迁移。此前页面稳定性修复保留。
