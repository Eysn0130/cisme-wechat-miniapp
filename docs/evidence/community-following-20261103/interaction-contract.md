# 关注频道交互约定

依据：PRD V2.1-R4 `COMM-FOLLOW-01..05`，原生微信小程序现有组件和导航。保留原视觉及发布权限。

| 状态或触发 | 展示与操作 | 退出或恢复 |
| --- | --- | --- |
| 精选 | 精选与关注并列，选中标记和点击区域一致 | 点击关注进入该账号动态 |
| 游客点击关注 | 用户主动进入既有登录流程 | 登录成功回关注；取消回精选 |
| 首次读取 | 使用既有不占内容高度的加载指示器 | 成功显示实际结果；失败显示重试 |
| 已有内容后刷新 | 保留当前账号已确认卡片 | 成功替换第一页事实；失败保留卡片并提示 |
| 已确认空动态后刷新 | 保留空状态及发现作者入口 | 新公开帖子出现后显示卡片；读取错误不能伪装为空 |
| 滚动分页 | 全局游标读取、追加且去重；已有卡片不重排 | 没有下一页即结束；失败可重试 |
| 返回社区或下拉刷新 | 重新读取关注作者的新公开帖子及权限事实 | 原位置保留到新结果；结束原生下拉状态 |
| 取消关注、屏蔽、下架、撤回 | 按服务端最新事实过滤动态 | 下一次进入、返回或刷新同步 |
| 离页、账号或环境变化 | 取消页面请求，过期成功及失败均忽略；不复用其他账号内容 | 当前账号重新鉴权读取 |
| 打开创作面板或正在处理操作 | 下拉刷新不打断已有创作及操作 | 关闭面板或处理完成后可正常刷新 |

关注页不混入邀请任务、全局搜索结果或未关注的精选。标题展示「关注动态」；卡片继续使用既有原生双列布局和正确的文章详情路径。没有增加实时订阅、定时刷新、推送或新手势。
