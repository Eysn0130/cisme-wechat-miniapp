# 管理员用户管理交付

实现 PRD **UM-01–UM-08**。用户确认的三张设计落为同一套原生页面：五种表格、概览/资料/业务/日志详情、完整详情页，以及保留的商业会员/费率页面。

- 管理中心 → 用户管理；昵称、会员编号和本人实际保存的头像同源；头像复用现有本地 JPEG 缓存，界面不传输 Base64 数据。账号、建档、商业资格、分享官资格独立显示。
- 资料 / 消费 / 活跃 / 权益 / 分享官：组合筛选、排序、字段选择、分页、选择和导出。手机号查询经只读 POST，避免号码进入访问 URL；普通 GET 拒绝完整手机号。
- 同一会员下查看订单/售后、护理、积分、券与兑换、分享官/归属、推广订单、月结、公开帖子/评论、客服、地址、隐私请求和操作记录。来源跳转携带对象 ID；既有管理页面同步按会员与对象过滤。
- 联系资料点击说明用途后临时显示，60 秒或离页清空；不进入 CSV、本机草稿或日志。护理、联系资料、汇总导出三项独立权限；资格管理不会同时开放佣金/月结。原订单、客服、履约、财务、隐私职责继续生效。
- 积分按原账本投影读取，管理查询不发放/扣减积分；真实支付与成功退款先聚合再连接。佣金按单计算后汇总，已登记回收不再显示为待回收。已取消的活动领取订单仍能准确查看。
- 从单个会员进入活动或月结时，隐藏全局配置、全名单导出及全员月结生成。发券仍需实际获奖依据；本轮没有自动发券、授予分享官资格、实际付款或修改会员资产。
- 旧商业会员与双人费率复核逻辑移至同分包的 `commercial/index`，保留原测试，不以新版表格替换其业务约束。
