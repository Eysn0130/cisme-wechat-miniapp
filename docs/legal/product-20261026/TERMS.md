# CISME 用户协议

更新日期：2026年10月26日

生效日期：2026年10月26日

CISME 由熹芃（上海）生物科技有限公司运营。我们通过微信小程序提供品牌内容、日常护理指引、护理记录、活动与权益查询，以及客服服务。请在登录前阅读本协议和《隐私保护指引》。

## 1. 账号与登录

您可以先浏览公开内容。需要保存个人记录或使用账号功能时，请使用本人的微信登录；首次登录会创建 CISME 账号。

头像、昵称及其他选填资料由您自行决定是否提供。微信登录不会自动获取您的手机号、微信号、通讯录或支付密码。不同功能需要的资料和权限，我们会在使用时说明；拒绝非必要信息，不影响其他无需该项信息的服务。

请妥善保管微信账号，不向他人提供密码或验证码。退出登录会结束当前设备上的登录状态，不等于注销账号或删除已有记录。您可以在“隐私与数据权利”申请处理个人资料。

## 2. 内容与社区

社区中的品牌精选由运营人员发布，内容和配图应为原创或已获授权。登录后，您可以点赞、收藏或关注作者，也可以随时取消。

这些操作仅表示您的内容偏好，不代表购买、领取权益或授权其他用途。护理记录和私有投稿不会因点赞、收藏或关注而公开。需要公开展示您的内容或资料时，我们会另行说明展示范围，并取得相应授权。

请尊重他人的知识产权和个人信息。不要提交侵权内容、无关证件、密码、验证码、他人隐私或其他违法信息。如发现问题，可通过客服反馈。

## 3. 护理记录、活动与权益

护理周期由您确认开始。完成页面中的四个步骤并选择护理后的感受后，可保存相应的周期记录。请按自己的实际使用情况填写；护理知识和个人感受记录不能代替专业诊断或治疗。

活动参与、投稿、审核、补充材料和申诉，按对应页面公布的规则办理。提交私有材料不等于公开发布，也不意味着将其用于其他目的。对处理结果有疑问，您可以在原记录或客服中提出。

积分、活动资格和其他权益的范围及使用条件，以相应规则和本人记录为准。页面展示不代替权益确认，也不等同于现金收入或已经完成的商品交易。购买、支付、售后等服务，以相应页面实际提供的功能和规则为准；未开通的服务不受理相应交易，不会因此产生扣款。

## 4. 联系客服

人工客服接待时间为每日北京时间 09:00–22:00，其他时间可以留言。我们会在接待时间处理，复杂问题可能需要核对资料或进一步沟通。

您可以在小程序内进入客服，也可以通过“隐私与数据权利”提交相关申请。无法登录时，可使用该页的“无法登录？联系微信客服”入口；能否进入会话及消息送达情况，以微信平台实际结果为准。微信“反馈与投诉”是平台反馈渠道，与 CISME 客服分别处理。

处理过程中如遇中断，请保留原问题或申请编号，在同一渠道继续联系。提交成功仅表示我们收到请求，具体进度和结果请查看回复。

## 5. 个人信息与服务变更

我们按照《隐私保护指引》处理个人信息。您可以申请查阅、复制、更正、删除资料、撤回授权或注销账号。申请处理完成或原用途结束后，不再必要的资料会被删除或匿名化；依法需要保留或涉及未结争议的必要资料，将限制使用并定期复核。

普通咨询记录自结案起保留三个日历月；直接关联实际交易的必要客服、售后证据，按交易完成或售后结束中较晚时间起三年的业务基线处理。不同资料分别判断，不因同一会话而统一延长保存。

涉及重要服务内容或个人信息处理方式的变更，我们会向您说明；依法需要重新确认的，将另行征求您的同意。您仍可依法向有关部门反映问题或行使其他权利。

未满十四周岁的用户，请勿独立使用需要提交个人信息的功能。我们会通过客服核实和处理相关误提交。
