# CISME 用户协议

更新日期：2026年11月3日

生效日期：以本版本实际发布并向您展示的日期为准。

CISME 由熹芃（上海）生物科技有限公司运营。我们通过微信小程序提供品牌内容、日常护理指引、护理记录、活动与权益查询，以及客服服务。请在登录前阅读本协议和《隐私保护指引》。

## 1. 账号与登录

您可以先浏览公开内容。需要保存个人记录或使用账号功能时，请使用本人的微信登录；首次登录会创建 CISME 账号。

头像、昵称及其他选填资料由您自行决定是否提供。微信登录不会自动获取您的手机号、微信号、通讯录或支付密码。不同功能需要的资料和权限，我们会在使用时说明；拒绝非必要信息，不影响其他无需该项信息的服务。

请妥善保管微信账号，不向他人提供密码或验证码。退出登录会结束当前设备上的登录状态，不等于注销账号或删除已有记录。您可以在“隐私与数据权利”申请处理个人资料。

## 2. 内容与社区

社区中的品牌精选由运营人员发布。体验版同时提供普通帖子创作：登录后，您可以保存私人草稿，或明确点击“去发布”，将当前正文、选择的图片和社区公开身份展示给其他浏览者，并进入社区列表及关注者的动态。您应拥有相应内容的发布权利。

存草稿不会公开内容。普通帖子的当前版本经微信自动内容安全检查通过后直接公开，不需要发布前人工审核；图片检查尚未完成时显示发布中，检查失败或结果不确定时不公开。您可以修改后重试、删除自己的帖子，或举报、屏蔽不希望看到的内容。删除后停止在本服务公开展示，已经被他人浏览或另存的内容无法保证一并收回。

您仍可点赞、收藏、关注作者，以及发表评论和回复，并可取消互动或删除自己的评论。

您主动发布的评论和回复，经必要的自动内容安全检查通过后，在对应文章下公开展示；作者身份按您已选择的公开资料或默认社区身份显示。删除评论后停止公开展示，回复和相关记录按实际状态处理。

这些操作仅表示您的内容偏好，不代表购买、领取权益或授权其他用途。护理记录和私有投稿不会因点赞、收藏或关注而公开。需要公开展示您的内容或资料时，我们会另行说明展示范围，并取得相应授权。

请尊重他人的知识产权和个人信息。不要提交侵权内容、无关证件、密码、验证码、他人隐私或其他违法信息。如发现问题，可通过客服反馈。

## 3. 护理、积分、交易与活动

首次会员资料在同一登录流程内确认；已有资料不重复询问。基础建档完成后进入护理。日常护理按实际用过的净润洗发水、净屑洗发水和护理精华多选，保存当天日期、产品及感受；同日调整不会重复领取已发积分。护理页下方记录胶囊进入护理记录。历史周期及四步事实仅按本人数据权利和必要追溯规则保留，不再作为日常护理流程。

积分奖励及价值、有效期、抵扣和兑换条件以当时生效的积分规则和本人的账本为准。首次建档奖励、每日有效护理、连续奖励、购物倍率与生日权益由服务端核验；同一来源不重复发放。积分可按规则用于商品抵扣或兑换，不是现金，不提供现金提现。纯积分兑换仍须满足真实积分、库存、配送及商品适用条件。

购买时核对商品、规格、数量、收货地址、优惠券、是否使用积分及实际费用。提交订单按规则预占相关积分、优惠券与库存；支付结果由真实支付渠道和服务端核验，不以客户端提示代替。未支付、取消、超时、退款或售后按原订单锁定的规则处理并核对权益。

配送范围、运费、时效及售后说明在商品和订单详情可查看。依法支持七日无理由退货；商品完好及必要一次性密封包装条件按实际商品和适用规则判断，不把拆封一概视为不退。商品问题、错发、漏发和运输问题由客服核实处理；不限制您依法享有的权利。

活动旅行套装仅向公司确认的获奖会员发放，同一会员一张兑换券、净润与净屑二选一。券有效期、配送和收货后的正装券以实际活动规则及到账记录为准；普通注册不等于获奖。取消、缺货或过期按当前券和订单状态处理，不虚构领取或发货。

旧投稿任务、发布证明上传及发布前人工审核流程已停止，私人草稿、护理记录和旧投稿不会因此自动公开。

### 分享官与推荐

会员可免费申请分享官，公司审核后使用；没有购买或囤货门槛，无上下级抽佣。客户默认永久归属首次有效推荐人，客户可在“我的推荐人”预览并确认更换。自购不计佣，更换推荐人及后台改规则只影响以后新建订单，历史订单按锁定规则处理。

佣金以核验后的商品现金实付为基础，不包含运费及优惠券、积分折抵；未付款或取消不计佣，退款按实际事实追加冲回。满足原订单锁定的收货等待期且无相关售后争议后，按月结规则核对。财务审核扣税和收款资料后人工付款，再登记实际流水；登记、预计佣金或可结余额均不等于款项已到账。您可在本人订单及结算记录查看来源、税额、实付和必要的冲回处理。

## 4. 联系客服

人工客服接待时间为每日北京时间 09:00–22:00，其他时间可以留言。我们会在接待时间处理，复杂问题可能需要核对资料或进一步沟通。

您可以在小程序内进入客服，也可以通过“隐私与数据权利”提交相关申请。无法登录时，可使用该页的“无法登录？联系微信客服”入口；能否进入会话及消息送达情况，以微信平台实际结果为准。微信“反馈与投诉”是平台反馈渠道，与 CISME 客服分别处理。

处理过程中如遇中断，请保留原问题或申请编号，在同一渠道继续联系。提交成功仅表示我们收到请求，具体进度和结果请查看回复。

AI 客服由 DeepSeek 提供模型推理，处理必要的咨询文字和有限上下文；相关接收方与资料处理见隐私指引。AI 不能办理退款、修改权益或代替人工确认，您可主动申请人工。

## 5. 个人信息与服务变更

我们按照《隐私保护指引》处理个人信息。您可以申请查阅、复制、更正、删除资料、撤回授权或注销账号。申请处理完成或原用途结束后，不再必要的资料会被删除或匿名化；依法需要保留或涉及未结争议的必要资料，将限制使用并定期复核。

普通咨询记录自结案起保留三个日历月；直接关联实际交易的必要客服、售后证据，按交易完成或售后结束中较晚时间起三年的业务基线处理。不同资料分别判断，不因同一会话而统一延长保存。

涉及重要服务内容或个人信息处理方式的变更，我们会向您说明；依法需要重新确认的，将另行征求您的同意。您仍可依法向有关部门反映问题或行使其他权利。

未满十四周岁的用户，请勿独立使用需要提交个人信息的功能。我们会通过客服核实和处理相关误提交。
