# 微信隐私保护指引填写候选

仅供将来正式版本配置使用；本轮不修改公众平台现网指引或任何审核流程。当前用户报告“小程序备案 管局审核中”，不是代码版本审核证据。

| 平台信息项/能力 | 候选用途 | 启用前核验 |
| --- | --- | --- |
| 头像、昵称：chooseAvatar / nickname | 用户主动完善本人会员资料；可选社区作者展示另行许可与审核 | 与账号入口、默认身份、关闭展示后的行为一致 |
| 手机号：getPhoneNumber | 用户主动绑定，以提供明示的会员服务和冲突核验 | 当前生产是否启用、独立授权、解绑及密文/索引处理 |
| 收货地址：wx.chooseAddress | 用户主动选择配送地址，支持确认与编辑 | 实际字段、加密地址快照、订单和售后用途一致 |
| 图片：wx.chooseMedia 等 | 护理记录、投稿、客服附件或头像 | 各入口只索取必要类型；原图/派生图/元数据及删除范围分别说明 |
| 剪贴板：wx.getClipboardData | 用户主动点击粘贴作品或平台链接 | 不在后台或页面加载时自动读取 |
| 设备信息：wx.getDeviceInfo 等 | 原生页面布局、安全区和必要性能诊断 | 不扩大为持续设备指纹或跨应用追踪 |
| 订单、支付及物流 | 完成订单、支付退款、配送及微信发货同步 | 与实际商户绑定、付款者、交易号、承运商和掩码电话一致 |
| 文字、护理及客服材料 | 保存本人记录、提供客服、处理投稿和争议 | 敏感内容的必要性、独立同意及第三方边界须补齐 |

正式主体、有效联系渠道、保存期限规则、第三方接收方与用户权利处理方式必须填真实批准值。源码声明的 requiredPrivateInfos、WXML open-type、实际 wx API 与本清单逐项核对；不能因为某接口声明在包内就认定已获平台同意。

技术基线见[个人信息清单](../../privacy/miniprogram-personal-data-inventory.json)和[主体数据关系表](../../privacy/subject-data-map.json)。本轮 schema 分母为 126 表；数据关系图不是完整导出/删除实现或批准依据。

官方依据：[用户隐私保护指引填写说明](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/) 与 [隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize)。平台现网指引与提审版本指引有不同入口和生效范围；未来操作前必须匹配具体版本并取得相应提交批准。
