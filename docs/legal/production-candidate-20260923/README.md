# 2026-09-23 正式协议正文候选

`用户协议.md` 与 `隐私政策.md` 是附件第三、四部分的消费者正文，去除了附件中的内部施工说明。当前仅为源码候选，尚未生效。正文沿用现有 `/v1/legal` 与原生 `pages/legal` 的发布路径；现有会员注册按服务端当前生效版本记录同意，不会因本目录新增而自动生成同意。

相对 2026-09-22 候选，本稿不把“72 小时发货”“全场包邮”“工程会员 12 个月”写成既定经营承诺；逐单退货指引、明确申请时间、退款与实物分别留痕遵循本轮业务流程。不得把该文本直接复制到微信公众平台或数据库。

`scripts/prepare-legal-documents.ts` 从这两份正文和一份经过业务核验的 JSON 事实输入生成既有发布器使用的 JSON 文档。输入必须包括平台绑定的真实运营主体、实际销售者、无需登录的公开联系渠道、各项核验依据、13 类资料分别适用的保存/清理规则，以及已实际接线的外部接收方。生成的三份配套清单会直接附在隐私政策正文内由原生协议页公开阅读；内部核验来源不进入消费者正文。输出使用独占创建，不覆盖历史文件。`publish-legal-documents.ts` 在事务发布前拒绝模板占位、候选/未生效字样、主体/渠道不一致和缺失的配套清单。

经营方已明确确认运营主体“熹芃（上海）生物科技有限公司”、唯一正式联系渠道为现有微信小程序客服，以及交易与关联售后记录的三年业务保留基线；主体和渠道已写入候选正文。分类原则见 [经营事实确认](../CONFIRMED-OPERATING-FACTS-20260923.md)。现有账号内客服尚需正式微信环境实收验证；已注销账号可在同一小程序用新的微信码进入原隐私请求记录。其他无法登录的用户仍缺经过验证的客服到达路径，不能把微信“反馈”冒称既有客服。普通咨询期限由独立配置控制，不凭空写固定天数。第三方接收方清单仍需按实际接线核对，正式导出/删除/注销也需完成。因此本目录尚无可直接发布的完整事实 JSON，未向生产协议发布新版本。发布时还须核对微信后台隐私指引、当前原生包和实际生产配置。
