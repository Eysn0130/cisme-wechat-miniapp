# 会员入口、境内迁移与页面刷新复盘

更新时间：2026-09-09 17:17（上海时间）。本报告记录已实施的改动、真实部署证据和仍需验收的边界。

## 已完成的业务闭环

首次打开进入会员入口，用户可自行阅读协议并微信登录，也可不勾选协议直接浏览公开社区。选择游客后再次进入默认回到社区；有有效本机会话时直接进入护理页。游客点击护理、记录、我的等会员功能时先进入登录，保存原目标；成功登录后返回目标。公开文章和隐私联系入口保留游客访问能力。

微信首次登录按 AppID + OpenID 幂等建档，重复登录复用同一个会员。注册本身不授予护理周期资格、不发积分、不开放交易，也不授予团队审核权限。昵称、微信号和手机号都是会员资料，不代替微信身份，不触发账号合并。Lucky-Healthy-Joker 已按运营者确认关联至指定真实会员，并记录审计；第二位待提供，未推断或创建。

微信登录返回应用内身份标识；不能自动读出用户自行设置的微信号。微信号改为本人选填或本人确认登记，界面说明其联系用途。手机号只有用户主动触发平台授权后才可取得；已实现加密保存、脱敏展示和冲突检查，但当前平台能力未启用，登录不等待手机号。微信身份标识与微信号的区分参照[腾讯云微信登录说明](https://cloud.tencent.com/document/product/1441/68677)，同时以当前微信 SDK 类型及实际接口响应核对。

## 腾讯云已成为当前运行环境

主数据库已迁至腾讯云上海 PostgreSQL 16；API 使用腾讯云 CloudBase，后台任务在上海服务器运行，照片与加密备份使用腾讯云上海 COS。当前服务器可承载此阶段，不需要再购买数据库产品。

迁移时先暂停旧后台任务并暂时拒绝 API 写入，再为旧库全部 46 张业务表增加写入阻断。最终复制校验中，46 张表的行数和内容摘要均一致；媒体对象为 0，因此没有假称完成不存在的照片复制。新库启用后移除仅目标库上的迁移写锁，恢复新 API 写入并启动上海 Worker。旧 CloudBase Worker 保持暂停，旧 Render 服务已在控制台确认 Suspended。旧 Supabase 历史副本仍是受限、只读的退役副本，尚未物理清除，不能宣称历史境外数据已全部删除。

云 API 到数据库采用 TLS 1.3 实测连接、服务端证书验证、客户端证书验证和密码认证。缺少客户端证书、明文连接及不可信服务端证书均拒绝。旧 Supabase CA 环境配置已从上海服务移除。数据库证书备份保存在本机受限目录，不进入源码。

新协议版本 `2026-09-09-v2-domestic` 已发布到当前数据库；原生微信开发者工具通过真实云 API 读到该版本及腾讯云上海存储条款。新注册不再要求境外存储单独同意；旧协议及同意记录保留原版本。本次没有代替用户勾选协议或生成同意记录。

## 加载为什么慢，具体怎样改

原链路存在跨境数据库往返、重复生命周期请求、串行独立读取，以及返回页面时先清空已有内容的问题。本次分别处理，避免用长期缓存掩盖权限或业务状态变化。

| 场景 | 本次实现 | 刷新边界 |
|---|---|---|
| 登录入口 | 协议只在 onShow 发起一次；手机号与资料并行读取；禁用手机号时跳过阻塞步骤 | 服务端注册事务再次验证协议版本 |
| 同时读取相同接口 | 相同身份、目标、参数的 GET 合并进行中的请求 | 不持久缓存已完成响应；写操作前后失效 |
| 护理、记录、我的返回 | 同一会话保留已有展示，同步刷新 | 刷新期间业务动作受保护；失败清除失效权限 |
| 社区切换与返回 | 先保留内容，公开 feed 与身份相关辅助读取并行 | 请求失败时不继续展示可能撤销的用户内容 |
| 快速离开页面 | 请求代次及页面存活状态阻止迟到结果覆盖 | 旧会话响应不能写入新账号页面 |
| 底部导航 | 相同选中状态不重复 setData；游客在切页前拦截 | 原生 tab 页保活，非 tab 页按原生栈语义管理 |
| 投稿草稿 | 首次可见后读取；返回时重新验证操作资格 | 保留输入，不把旧资格当作可提交凭证 |
| 协议加载 | 显示“正在读取协议”，不再把等待误报为未发布 | 未取得当前协议时登录仍保持禁用 |

不对护理、积分、授权、审核结果使用跨会话缓存。切换账号会失效请求；服务器权限始终为准。当前没有宣称所有页面永不刷新，也没有用伪造延迟或固定动画取代真实接口结果。

## 性能与验收证据

自动化验证：161 项单元测试、56 项集成测试通过；TypeScript、构建、契约及原生包预算检查通过。最终小程序源码摘要 `e258ef4d66bd25cd8841555b5c162453fdd9679d66d4835e6dd95de119904f38`，148 文件、16 路由、1,735,865 字节。开发者工具官方上传会进行原生编译，开发包与体验版/正式版状态分别记录，不能相互替代。

原生现场已观察到：会员资料来自真实云 API；现行境内协议；退出本机会话后不勾选协议进入公开社区；游客点击护理先到会员登录；新入口协议读取正常且没有境外勾选项。此次退出仅清除开发者工具本机会话，后台会员数据未删除。完整 16 路由所有状态、不同机型、真实用户新协议登录及手机号授权仍未全部验收，当前全状态验收标记保持未通过。

## 业务复盘与后续升级顺序

1. 会员与资格分开。公开注册不需要内部名单；护理周期按签收/活动资格开通。界面应持续解释“已是会员、尚无周期”，避免将零数据当故障。
2. 社区与经营分开。精选可公开浏览；会员投稿经用途许可、审核与独立复核后发布。真实媒体上传、撤回后的隐藏和独立团队账号复核仍需真机走完。
3. 邀请与返佣分开。现有来源、有效窗口和幂等规则保留；支付、退款、对账、返佣尚未形成完整交易闭环，商品目前只读。应先补交易状态机和退款冲正，再呈现收益承诺。
4. 资料与权限分开。微信号和昵称更新只能修改本人资料，不能改变团队角色；同手机号不自动合并会员。
5. 保活与权威状态分开。优先保留视觉内容及草稿；恢复可见时重新校验资格、许可、积分和队列。下一轮真机重点采集冷启动、热返回、弱网失败、切账号和后台恢复数据，按页面而非单一平均值决策。
6. 运行与发布分开。腾讯云生产数据链路已切换；ICP/小程序备案、微信后台隐私能力、体验版设置及团队扫码验收仍是平台发布事项。开发包上传成功不代表正式上架。
