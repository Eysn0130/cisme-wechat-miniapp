# CISME PR #2 商业与社区发布决策表（2026-09-13）

权威产品基线为 `CISME-产品需求文档-PRD-V2.1-R4.md` §6.8、§6.6.2、§7。本文只记录本轮隔离实现所用参数、尚缺的正式决策和证据，不修改 PRD 已确定的业务状态，不授予生产权限。

| 决策 | 隔离工程实现 | 正式启用前的决定与责任 | 当前状态 |
|---|---|---|---|
| 商业会员资格 | 管理员授权限、有效期，登录账号本身不自动获得计佣资格；续期不会缩短已有时间 | 产品负责人确认准入、有效期、续期、暂停、申诉与存量用户处理；财务确认利益披露 | 未批准 |
| 推荐归属 | 被推荐人主动确认唯一直接关系；A→B→C 不越级计佣；分享点击不生现金权利 | 产品/法务确认老用户、复购、关系争议、身份合并、撤销与有效期 | 未批准 |
| 费率 | 隔离默认 2000 bps、成员单独 2000–3500 bps；提议与独立批准、版本和生效时间被记录；费率按下单快照 | 财务/产品批准版本化全局与个别费率、例外审批、计划时间晚于审批时间时的生效解释 | 未批准 |
| 可计佣基数 | CNY 整数分，合格商品现金额；运费及不支持的券/积分分配在当前隔离链路拒绝；累计退款按原单重算目标冲回 | 财务/税务批准 SKU 范围、优惠和积分顺序、分摊、四舍五入、税基及退款争议规则 | 未批准 |
| 付款异常 | 已保存支付意图绑定原单与付款人；未知状态查原商户单号；渠道关闭后本地意图与订单取消在一个事务提交；晚到已关单付款进异常队列，不自动改付或退款 | 支付负责人、客服与财务批准超时、到期库存、晚到付款自动/人工退款及客户通知时限 | 未批准 |
| 售后及履约 | 隔离环境以凭据编号/摘要和异人复核模拟交付；佣金受益人不能核验自己的释放，亦不能审批关联退款；未决退款申请阻止佣金释放 | 履约/客服/法务确认合法发货与签收来源、无物流服务形态、售后窗口和返还规则 | 未批准；真实凭据未接入 |
| 佣金结算 | 可用金额原子预占、异人复核，第一次向渠道提交前锁定订单并重核退款与可用余额；转账 `SUCCESS` 的签名原单查询才记已结算 | 财务/税务批准最低金额、频率、实名/收款身份、税务、追偿、商家转账场景和双人/小团队替代控制 | 未批准；场景资质未取得 |
| 对账 | 隔离交易账单支持签名申请、摘要验证、逐行匹配、内部已付订单反向缺行检查与不可变差异记录；原单异常可重查/重驱 | 财务确认每日交易、退款、资金流水、商家转账和内部佣金四方核对，退款缺行反查、例外关闭证据和账单保存期 | 部分隔离实现；真实账单未验 |
| 公开社区 | 未提交修订私有；文字/图片安全、人工复核与独立发布；举报记录当时公开版本，受举报人不能自行驳回，评论按最新安全结果审核 | 内容负责人批准人员分工、未成年及违规内容处置、申诉时限、昵称安全、加密回调及扫描并发策略和平台账号实测 | 未批准；公开 gate 关闭 |
| 个人信息 | 订单、地址、OpenID、内容及账单摘要按目的限制；本地未保存草稿按账户/帖子/版本存储，不复制 bearer，启动/前台/编辑时清理过期项、换会话清空 | 隐私/法务批准真实内容、物流和财务事实保存期、删除例外、本地备份正式告知与合法域名 | 未批准 |

所有生产迁移、真实支付/退款/转账、公开 UGC、正式体验版发布，都需要单独授权。隔离本地的 HTTP 渠道、合成账号与签收摘要不能作为真实平台或合法经营证明。当前未取得用户所述共享补充业务对话原文；其中可能存在的新决策不得从链接或摘要猜测合并。
