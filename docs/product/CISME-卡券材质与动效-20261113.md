# 卡券材质与动效

Reading this as: native WeChat membership and benefit surfaces for CISME members, with restrained pearlescent foil, preserving the approved plum card, typography and real balances. Taste dials: DESIGN_VARIANCE 5 / MOTION_INTENSITY 4 / VISUAL_DENSITY 3. Mobile UX and WeChat constraints take priority over web examples.

保留会员身份、积分、编号及券金额、期限和状态。材质为铂银、香槟与淡紫的薄层折射，不新增操作说明或装饰标签。

- 焦点：会员卡首次出现、长按彩蛋，以及收到真实领取回执后到账的正装券；单次 640–760ms 光带，不循环、不阻塞操作。
- 连续性：文字、数字和卡体固定；移动的只是卡面反光。按压不叠加整卡透明度，避免文字变淡。触摸每40ms最多一次局部更新，松开回正；纵向滑动交还原生页面，拖动不误点兑换入口。
- 反馈：已有确认、失败、资格和金额始终由接口决定；光效不提前宣告领取或支付成功。
- 预算：原生 WXML/WXSS/TypeScript，无外部动画库、WebGL、传感器、纹理下载或逐帧定时循环。隐藏时停止焦点动效，低性能设备与系统减少动态效果有静态材质路径。光带结束由原生 animationend 归位，不保留扫光状态。

参考：[HoloCardPreview](https://github.com/Jdb156158/HoloCardPreview) 的分层光照与手势区分；[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 的短促反馈和可中断原则；[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的层级与可读性。采用原生实现，不引入网页预览器、翻面流程或 Apple 框架。Impeccable 使用 animate / craft-floor 的原生适配规则，Taste 只作视觉判断。

对比度：会员卡正文使用白色，底色高光与反光分开控制；按最亮渐变叠加的保守 sRGB 计算，触摸/扫光状态分别约4.69:1/4.66:1。此为分析预算，不等同于真机像素与可访问性认证，详见 foil-contrast-budget.json。

验收：真实原生渲染、指示线/卡面文字对比、触摸/纵向滚动/取消/隐藏/换账号、减少动态效果、真实业务回执。模拟器不等于真机性能验证，当前无可连接手机。
