# CISME 产品文档

本目录保存可公开审阅的完整产品需求与追溯资料。产品、设计、开发、测试、供应商询价和验收的唯一生效需求基线是：

- [CISME 产品需求文档（PRD V2.1-R4.1）](CISME-产品需求文档-PRD-V2.1-R4.md)

## 文档层级

- `CISME-产品需求文档-PRD-V2.1-R4.md`：稳定文件名；文件内的 V2.1-R4.1 是当前生效的产品目标与分阶段实施基线。
- `archive/`：已被替代的历史 PRD 与退役清单，只用于来源追溯，不得作为当前实现依据。
- `reference/prototype/`：原型范围决策与 PRD 追踪材料，用于核对原型和生产目标之间的差异。

## 使用规则

1. 需求引用使用稳定的章节、状态机、事件、TBD 和验收 ID，不依赖本地绝对路径。
2. PRD 中的 `R0 CORE`、`R0 GATED`、`R1`、`R2` 和 `TBD` 具有不同启用条件；“完整保留”不表示全部能力都应在首发同时上线。
3. 历史资料与当前 PRD 冲突时，以 V2.1-R4.1 的冲突修正、生效口径和决策账本为准。
4. PRD 定义目标需求，不自动证明当前代码已经实现；实现状态和证据以仓库中的交付台账、Release Audit 与测试结果为准。

V2.1-R4.1 全面保留两份 V1.0 源需求的可追溯业务意图，并明确记录平台化、延期或舍弃的裁决。已识别的身份、积分双计、UGC 审核、订单/库存、许可、AI 越权和排期等错误不因保留历史意图而恢复。
