# 护理首页：04 品牌与护理分区

用户明确选择 `04-split-brand-care`，授权原生实现与最新体验版发布。`approved-04.png` 是已选设计参考，不是本轮源码的运行截图。

CISME 作为平台标识位于顶部；AIGERONG 爱格荣使用用户 PDF 的原始字标，出现在上半区的产品素材内。下半区沿用居中的今日护理、真实产品使用选择、唯一实心主按钮及 84% 宽的护理记录胶囊。“详情”继续进入本人护理记录，不恢复周期与四步历史界面。

用户审阅长屏截图后指出下部留白过多。高度至少 880px、宽度不超过 600px 的竖屏中，素材区增至宽度的 67%，同时放大品牌标题、护理标题、产品图标与文字、主按钮文字；护理区按实际可用高度分配间距，连续记录与底部胶囊之间保留约 36px，而不是留下单独的大片空白。短屏沿用已验证的紧凑间距与纵向滚动，不为填满长屏而挤压短屏按钮。

## 交互契约

对应 PRD `CARE-CAMPAIGN-01` 至 `CARE-CAMPAIGN-06`。

| 触发 | 可见反馈与后续行为 |
| --- | --- |
| 首次进入 | 首图和下一张优先请求。图片几何尺寸预留；成功后仅透明度淡入，不移动护理按钮。当前图片未完成时不自动切到尚未完成的下一张。 |
| 自动播放 | 使用微信原生 `swiper`，每张稳定展示 5 秒，420ms 缓入缓出，第四张循环到第一张；没有逐帧 JS、`setInterval` 或常驻粒子效果。 |
| 手指接触或横滑 | 取消旧计时。手动横滑后，从手指离开且原生动画结束起停留 3 秒，随后恢复自动轮播；不在用户阅读或滑动中抢切。 |
| 轮播指示 | 仅保留四个圆点，不展示播放/暂停按钮。恢复自动滚动后各张重新按 5 秒停留。 |
| 弹层打开、切页、隐藏、滑出视口 | 停止轮播计时；返回且可见后从当前张重新停留。销毁时清除计时、观察器和本组件 GET 订阅，迟到响应不回写。 |
| 图片慢或失败 | 未完成图片不参与自动前进；失败展示稳定原生底图及文字重试，仍可浏览标题/进入真实目的地。全图失败时不自动轮转空占位；旧尝试回调不覆盖重试结果。 |
| 滑动后误触 | 转场及短暂收尾期间禁止素材跳转，只允许当前张的有效点击。非白名单目的地和商品编号被拒绝。 |
| 点击素材 | 品牌到商城；精华与套组仅绑定已发布、合格、人民币实际商品；无法核实时进入商城，不伪造商品或价格。选品进入现有客服，不新增重复问卷。游客沿用现有登录与补齐资料流程。 |
| 护理完成 | 保留原来的服务端记录、积分幂等和奖励动画；轮播不写用户护理、积分、订单或券数据。 |

## 素材与部署

四张原图按用户授权重组为 960×640 的纯图片底片，文案、价格、按钮为原生文字。`generated-assets.json` 留存原图、工具提示词及生成来源；JPEG 总计 131,050 字节，按内容 SHA-256 命名，放于 `assets/home-campaign/`，不进入小程序主包。官方字标从原始 PDF 路径导出 PNG，未重画字形。

公开图片只使用现有两个 API 合法 HTTPS 域名的四条精确内容地址。体验、正式文件分别存放，不接触会员对象或数据库。`infra/tencent/home-campaign-assets.py` 默认只读；实际安装须匹配服务器、文件摘要与刚读取的 Nginx 配置摘要。只平滑重载 Nginx，不重启 API/worker，并留存回退配置。四张素材均为已授权的品牌图，不公开其他目录。

## 验证边界

源码单测、原生模拟器、公开素材 HTTP 和上传回执分别留证。图片生成稿、网页参考、旧包截图不能作为新包原生验证。未连接获授权手机时，真机触摸、机型差异和设备帧率均记为待验，不承诺不存在任何卡顿。
