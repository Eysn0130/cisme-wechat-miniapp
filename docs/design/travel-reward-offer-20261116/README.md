# CISME 旅行洗护礼遇 · 三版设计稿

设计日期：2026-11-16。此稿为三版视觉提案，尚未选定、实现或发布。编号对应本次聊天中三张生图的实际展示顺序。

## 本轮设计约束

- 礼遇独立于100积分奖励，去掉原弹层的珍珠圆章、勾选封印、积分计数和相同动效。首次100积分仍按原流程先完成，再呈现本礼遇。
- 两套实物仅二选一：净润洗发露100mL＋柔光强韧护发乳100mL；控油净屑洗发水50mL＋同款护发乳100mL。
- 两张原广告照片重新适配：去掉画面上的大段广告文案，产品按组重新构图、放大，保留真实瓶型、瓶盖、标签和容量关系；不把整张海报缩成小图。
- 主操作为“立即领取”，次操作为无边框的“稍后领取”。展示礼遇时不默认选择套装，也不代填地址或自动兑换。
- 此次重新设计礼遇弹层；已认可的会员卡、活动券及正装优惠券设计继续保留。

## 第1张 · 礼盒揭幕

图稿：[01-gift-unveil.png](01-gift-unveil.png)

采用暖瓷白压纹纸、深紫缎带与轻微烫印细节。两套产品在同一纸质展台上分组陈列，标题“一份洗护，为你而来。”；礼物本身作为视觉焦点。适合强调收到实物礼物的仪式感。

| 项目 | 落地稿 |
|---|---|
| 容器 | 居中礼盒弹层，宽度视口减40px；圆角14–16px；内容最高不超过可用视口84%，窄屏和大字号允许内部滚动 |
| 图片 | 两套各保留一对完整产品，统一地面和光线；左右留出分组间距，不拼成四件赠品 |
| 标题 | 约30px、两行；中文衬线需系统可用字体回退，品牌字标使用现有正式资产 |
| 主次操作 | 深紫实心“立即领取”；纯文字“稍后领取”；触控高度至少44px |
| 入场构想 | 0–180ms遮罩渐入；100–480ms纸套上沿展开；240–700ms两套产品轻抬入位；最后一次细窄光泽扫过 |
| 兑换成功构想 | 已选套装进入纸套，纸套合拢并露出短句“这份洗护，属于你了”；约2秒后进入领取订单，无积分圆章或计数 |

## 第2张 · 双套装陈列

图稿：[02-product-atelier.png](02-product-atelier.png)

采用接近全屏的底部弹层，浅色背景、统一左侧文字、右侧大幅产品图。两套按上下两行展示，容量便于比较。标题“选一套，带回家。”；视觉更利落，产品阅读更直接。

| 项目 | 落地稿 |
|---|---|
| 容器 | 底部弹层；顶部圆角18px；安全区内固定主操作，产品区域可滚动 |
| 图片 | 右侧为两瓶完整组合，净润两瓶等高、净屑50mL小瓶低于护发乳100mL，不裁切泵头 |
| 文案 | 每行仅套装名、洗发产品容量、护发乳容量；不叠加功效段落、冗余标签或说明卡 |
| 主次操作 | 底部“立即领取”与文字“稍后领取”；图中右上“稍后”与底部重复，实际落地仅保留底部一处 |
| 入场构想 | 弹层280ms上移就位，两组产品在随后180ms内依次由清晰度和轻微位移进入；不重复扫光 |
| 兑换成功构想 | 已选组合平移到画面中央，另一套淡出，背景形成一条轻柔光带，约2秒后进入订单 |

## 第3张 · 旅行礼券

图稿：[03-travel-invitation.png](03-travel-invitation.png)

采用深紫纸质礼券、局部银紫烫印和细密线纹。浅色页面与深色礼券形成明显对比，两套产品仍以实物为主。以可收藏的礼券视觉表达惊喜，不新增面额、折扣或其他权益。

| 项目 | 落地稿 |
|---|---|
| 容器 | 居中礼券，宽度视口减40px；局部票根缺口、浅浮雕、柔和投影，避免整屏霓虹镭射 |
| 图片 | 两组真实瓶型嵌入一体化摄影区域，保持二选一的分组关系 |
| 层级 | 银色品牌字标、小范围精细线纹、浅色标题、产品、两项操作；文字区域保持纯净对比 |
| 主次操作 | 浅色实心“立即领取”；浅色无边框“稍后领取” |
| 入场构想 | 礼券轻抬进入，银箔折角在约500ms内揭开，产品显现；再进行一次低强度局部光带掠过 |
| 兑换成功构想 | 券面翻折过渡为已选产品与“礼遇已领取”，约2秒后进入订单；不将撕券动画当作实际核销结果 |

## 三版共用交互与业务契约

1. 打开管理员分享的统一活动链接。未注册用户在现有微信登录内完成手机号、头像、昵称缺失项和首次问卷；已有信息自动加载。
2. 只有真实100积分入账后才展示首次积分动画。该动画结束后，服务端按会员ID去重发本活动券，再显示礼遇弹层。两个奖励各自表达，互不叠加。
3. 点击“立即领取”打开两套组合的明确选择和地址确认；首屏不预选。选择一套后，确认地址及零元包邮，再点“确认领取”。
4. 点击“稍后领取”或关闭，只关闭弹层。券留在“我的 → 我的奖励”，期限按真实发券时间30天计算，不因重开而延长。
5. 兑换才核销券、扣套装实物库存并创建领取订单。领券、打开页面和观看动画均不占库存。
6. 净润、净屑各50套。缺货项禁用；另一套有货可继续领取。两套都没货展示真实状态，不显示虚假成功。
7. 只有确认成功才播放兑换成功动效。超时结果未知先核对同一操作，不能靠动画视作成功或重复扣券。
8. 切后台取消旧计时；恢复后按已确认事实展示。换账号/环境不能沿用上一账号弹层、地址或订单。
9. 礼遇到账弹层等待用户选择，不在2秒后自动关闭。兑换成功反馈可以约2秒后自动到订单，且允许用户立即查看。
10. “减少动态效果”使用静态状态和短淡入；不持续旋转、晃动、循环闪烁，不依赖实时模糊或重型3D；按钮无需等待动效完成才能操作。
