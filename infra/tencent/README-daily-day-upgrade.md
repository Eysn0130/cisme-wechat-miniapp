# 体验环境每日记录升级

`trial-daily-day-upgrade.py` 是独立的 schema100 → 101 升级入口。默认只读，只允许正式腾讯云实例上的 `/opt/cisme-trial`；正式环境不切换。

- 基线固定为实际运行的 a1899adc59f4 和已核验的100迁移制品。只加载其已审查的保护函数，不重跑旧迁移或旧应用升级。
- 候选必须为成功 push CI 的精确远端 main，在固定 Linux builder 中构建。旧100份 SQL、迁移器、包锁、配置及完整依赖树必须逐字相同；唯一增加101。
- 只读预检核实例、隔离数据库、六组密钥、关闭的业务入口、服务定义、20篇精选及候选制品。不输出个人事实或凭据。
- 一次性执行标记与既有运维锁防止不明结果重放。停止体验服务并排空连接后，记录原100字段的私有指纹，再创建并认证同机加密数据库快照，执行唯一迁移。
- 新迁移可增加日历日、当前版本和历史投影，不能修改任何原100字段、原始护理事实或先前的隔离时间。切换前核对所有原字段的指纹不变。
- 101之后旧100程序无法执行单日记录和删除合同，因此本入口没有旧应用回退、down 或数据库恢复动作。失败保持体验服务停止并保存保护状态，等待基于已知事实的向前修复。

`active` 检查本次自己的101记录和服务，不把旧100守卫误用于新 schema。备份仅认证同机数据库快照，不宣称完成异地灾备或恢复演练。阶段工具本地定稿时绑定全部输入摘要；遇不明阶段结果先读回已有任务与状态，不能重新发送同一次部署。
